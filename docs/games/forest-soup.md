# 게임 구상: 숲속 냄비 요리

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

• 경로: `games/forest-soup/`
• 상태: 2단계 고도화 Done (이번 범위)
• 갱신: 2026-11-11

---

## 1. 한 줄 놀이

숲속 친구를 위해 재료를 냄비에 **퐁당** 넣고, 냄비를 **톡톡·뱅글뱅글** 저어 수프를 만든 뒤 친구에게 **냠냠** 먹이는 놀이.

## 2. 감정 한 줄

“내가 만든 수프를 친구가 맛있게 먹었어!” — 뿌듯함과 포근함. 좋아하는 재료가 들어가면 더 크게 기뻐한다.

## 3. 코어 루프 (30초~2분)

1. **아이 입력:** 아래 재료(당근·버섯·옥수수·브로콜리·사과)를 콕 누른다.
2. **즉각 반응(시청각):** 재료가 냄비로 폴짝 날아가 **퐁당**, 수프 색·토핑·조각이 바뀌고 물방울 소리. 친구 취향 재료면 친구가 “오!” 하며 살짝 반긴다(정답 강요 없음).
3. **화면에 남는 변화:** 냄비 둘레의 뱅글 진행 링이 차오르고, 수프가 보글보글 끓는다.
4. **다시 하고 싶게 만드는 것:** 매 라운드 다른 숲속 친구가 와서 냠냠 시식 → 하트·뿅 반응(취향 재료면 더 큰 기쁨). 4그릇이면 다 같이 배부른 소프트 엔딩.

화면으로 설명하면 (3장면):

1. 냄비와 재료, 옆에서 기다리는 친구
2. 재료 퐁당 → 톡톡/뱅글뱅글 젓기 → 수프 완성
3. 친구 냠냠 시식 → 하트 → 다음 친구

### 3-1. 핵심 로직 (코드 없이 재구현 가능)

#### 상태 흐름

`cook` → (재료 ≥1 후 젓기 진행 1.0) → `serving` → `tasting` → `roundEnd` → (그릇 4개 미만이면 `cook` 반복 / 아니면 `ending`)

#### 재료·수프 비주얼

- 재료를 넣을 때마다 수프 RGB를 기존색과 재료색으로 혼합(가중치 ≈0.42↑).
- 수프 위 **토핑 레이어**: 넣은 재료 종류별 작은 점(토핑 이모지) + 재료 2종 이상이면 소용돌이(conic-gradient).
- 재료 조각(`soup-bits`)도 냄비 안에 남는다. 재료 3개 이상이면 `is-rich` 하이라이트.

#### 친구 취향 리액션 (정답 강제 없음)

| 친구 | 좋아하는 재료 |
|------|----------------|
| 토끼 | 당근 |
| 곰 | 버섯 |
| 여우 | 사과 |
| 사슴 | 브로콜리 |

- 어떤 조합이든 시식·완료 가능. 실패·감점 없음.
- 시식 시점에 취향 재료가 **한 개라도** 들어 있으면 `loved` 모드: 대사·하트 수·모션·효과음이 커짐.
- 취향 재료를 넣는 순간 친구가 짧은 미리 반김(“오!” 등). 강요 힌트 문구는 쓰지 않음.

#### 젓기 (만 3~4세 보정)

- **원형 드래그:** 각도 변화량 / (2π × 1.5바퀴) 만큼 진행.
- **톡톡 연타:** pointerdown마다 진행 가산. 첫 방문·첫 그릇은 약 0.17(≈6회면 완성). 이후·재방문은 0.08~0.11로 완화하되 톡은 계속 유효.
- 재료 0개면 젓기 진행 없음 → 재료 트레이만 흔들림 힌트.
- 첫 그릇 시각 힌트: 숟가락 공전 + “톡톡·뱅글뱅글” 큐 + 화살표·손 탭 애니.

#### 저장

- `KidsKit.store('forest-soup')`
  - `fed`: `{ rabbit: n, bear: n, ... }` 먹인 횟수
  - `visits`: 방문 횟수
- 레거시 키 `forest-soup-fed`가 있으면 첫 로드 시 `fed`로 마이그레이션.

## 4. 첫 90초

로비 진입 → 첫 **의미 있는** 터치까지:

• 막힐 수 있는 지점: “재료를 넣은 뒤 무엇을 해야 하지?” / 원형 젓기 동작이 낯섦.
• 막힘 완화: 첫 화면부터 재료 버튼이 큼직. 재료를 넣으면 숟가락·화살표·손 탭 힌트와 “톡톡·뱅글뱅글” 큐. 톡톡만으로도 첫 그릇 완성 가능. 4.5~6초 가만히 있으면 냄비/재료가 살짝 흔들림.

## 5. 변주·질림 방지

• 변주 축 (2개): **재료 색·토핑 조합**(수프 색·토핑·조각) / **숲속 친구·취향 리액션**
• 발견 레이어: 친구 취향 미리 반김 → 시식 때 큰 기쁨 / 토핑·소용돌이는 조합에 따라 달라짐
• 선택할 수 있는 것: 재료 종류·개수·순서 모두 자유. 정답 조합 없음.
• 목표 세션 길이: **3~5분**(그릇 4개) · 출구: 엔딩 “또 만들기 / 쉬자” + 플레이 중 `KidsKit.restButton`

**10회차 체크:** 재료 조합·친구·취향 적중 여부가 매번 달라 수프 비주얼·반응·스티커가 조금씩 새롭다.

## 6. 소프트 엔딩

질리거나 부모가 끊을 때:

• 끝나는 느낌: 4그릇을 먹인 뒤 “냠냠! 잘 먹었어!”(취향 적중 있으면 “친구가 정말 좋아했어!”) — 실패·점수·게임오버 없음.
• 현실·휴식 연결: 엔딩 “쉬자” + 상시 `restButton`. 재촉·과몰입 문구 없음 (§6-1).

## 7. 재방문 훅 (1개만)

유형: 수집·도감 + 돌봄·관계

• 한 줄: “돌아왔을 때 내가 먹인 숲속 친구들이 나무에 붙은 스티커로 반겨 준다”
• 저장: `KidsKit.store('forest-soup').fed` (+ visits)
• 반김: 재방문 시 환영 배너 + 스티커 통통 애니 + 힌트 “친구 스티커가 반겨요!”
• 금지: 경쟁·랭킹·완성 압박·미획득 결핍 문구 없음. 횟수는 작은 점으로만 표시.

## 8. 이번 범위 Done

**반드시 넣음 (≤3)**

1. 친구별 좋아하는 재료 리액션(정답 강제 없이 기쁨 증폭).
2. 수프 색·토핑 비주얼 변주 + 톡톡 젓기 보정·시각 힌트.
3. KidsKit 연동(store·rest·preload)·이미지 슬롯·재방문 스티커 보강·4그릇 호흡.

**다음에 미룸 (≤3)**

1. TTS 음성 안내.
2. 재료·친구 추가(계절 수프, 숲속 친구 더 보기).
3. 냄비 꾸미기·요리 도구(국자 색, 앞치마).
