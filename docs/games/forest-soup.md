# 게임 구상: 숲속 냄비 요리

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

• 경로: `games/forest-soup/`
• 상태: 구현 Done (이번 범위)
• 갱신: 2026-11-07

---

## 1. 한 줄 놀이

숲속 친구를 위해 재료를 냄비에 **퐁당** 넣고, 냄비를 **뱅글뱅글** 저어 수프를 만든 뒤 친구에게 **냠냠** 먹이는 놀이.

## 2. 감정 한 줄

“내가 만든 수프를 친구가 맛있게 먹었어!” — 뿌듯함과 포근함.

## 3. 코어 루프 (30초~2분)

1. **아이 입력:** 아래 재료(당근·버섯·옥수수·브로콜리·사과)를 콕 누른다.
2. **즉각 반응(시청각):** 재료가 냄비로 폴짝 날아가 **퐁당**, 수프 색과 재료 조각이 바뀌고 물방울 소리.
3. **화면에 남는 변화:** 냄비 둘레의 뱅글 진행 링이 차오르고, 수프가 보글보글 끓는다.
4. **다시 하고 싶게 만드는 것:** 매 라운드 다른 숲속 친구가 와서 냠냠 시식 → 하트·뿅 반응. 3그릇이면 다 같이 배부른 소프트 엔딩.

화면으로 설명하면 (3장면):

1. 냄비와 재료, 옆에서 기다리는 친구
2. 재료 퐁당 → 뱅글뱅글 젓기 → 수프 완성
3. 친구 냠냠 시식 → 하트 → 다음 친구

## 4. 첫 90초

로비 진입 → 첫 **의미 있는** 터치까지:

• 막힐 수 있는 지점: “재료를 넣은 뒤 무엇을 해야 하지?” / 원형 젓기 동작이 낯섦.
• 막힘 완화: 첫 화면부터 재료 버튼이 큼직하고 통통 튐. 재료를 넣으면 숟가락이 자동으로 뱅글 돌며 링이 보이고, 6~7초 가만히 있으면 냄비/재료가 살짝 흔들리는 시각 힌트(문구 압박 없음). 젓기는 원형 드래그뿐 아니라 톡톡 두드려도 조금씩 차오른다.

## 5. 변주·질림 방지

• 변주 축 (2개): **재료 색 조합**(수프 색·조각 변화) / **숲속 친구**(토끼·곰·여우·사슴)
• 발견 레이어: 친구마다 다른 냠냠 반응과 하트 색, 수프 위 증기·숟가락 궤적, 다 먹은 뒤 친구 나무에 스티커가 쌓임.
• 선택할 수 있는 것: 재료 종류·개수·순서 모두 자유. 정답 조합 없음.
• 목표 세션 길이: 3~6분 · 출구: 엔딩에서 “또 만들기 / 쉬자”

**10회차 체크:** 재료 조합과 친구가 매번 달라 수프 색·친구 반응·스티커가 조금씩 새롭다.

## 6. 소프트 엔딩

질리거나 부모가 끊을 때:

• 끝나는 느낌: 3그릇을 먹인 뒤 “냠냠! 잘 먹었어!” — 실패·점수·게임오버 없음.
• 현실·휴식 연결: “쉬자”는 로비로 돌아가는 부드러운 출구. 재촉·과몰입 문구 없음 (§6-1).

## 7. 재방문 훅 (1개만)

유형: 수집·도감 + 돌봄·관계

• 한 줄: “돌아왔을 때 내가 먹인 숲속 친구들이 나무에 붙은 스티커로 반겨 준다”
• 저장: `localStorage` (`forest-soup-fed`)에 친구별 먹인 횟수 저장.
• 금지: 경쟁·랭킹·완성 압박·미획득 결핍 문구 없음. 횟수는 작은 점으로만 표시.

## 8. 이번 범위 Done

**반드시 넣음 (≤3)**

1. 재료 퐁당 투입 — 재료가 날아가 수프 색·조각이 바뀌는 즉각 피드백.
2. 뱅글뱅글 젓기 — 원형 드래그/톡으로 진행 링이 차오르고 숟가락·물결 연출.
3. 동물 냠냠 시식 + 3그릇 소프트 엔딩 — 친구별 시식 모션, 하트, 친구 나무 스티커 저장.

**다음에 미룸 (≤3)**

1. TTS 음성 안내.
2. 재료·친구 추가(계절 수프, 숲속 친구 더 보기).
3. 냄비 꾸미기·요리 도구(국자 색, 앞치마).
