# 게임 구상: 음악 정원

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

• 경로: `games/music-garden/`
• 상태: Done (2단계 고도화)
• 갱신: 2026-11-11

---

## 1. 한 줄 놀이

구름을 톡톡 눌러 비를 내리고, 새싹을 쑥쑥 키워 꽃을 피운 뒤 꽃을 톡톡 눌러 연주해요.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **포근한 신남 + 뿌듯 + 안심** — "내가 비를 줘서 꽃이 폈고, 꽃을 누르면 예쁜 소리가 난다. 다음에 와도 꽃밭이 반겨 준다."

## 3. 코어 루프 (30초~2분)

1. 아이 입력: 위쪽 구름 3개 중 하나를 손가락으로 톡.
2. 즉각 반응(시청각): 구름이 말랑하게 톡 튀며 빗방울이 통통 떨어지고, 방울마다 물소리 음이 난다.
3. 화면에 남는 변화: 빗방울을 받은 새싹이 **퐁!** → 줄기 **쑥!** → 꽃봉오리 **봉긋!** → 꽃 **팡!** 순서로 자란다. 다 핀 꽃은 도·레·미·솔·라 중 자기 음을 가진다.
4. 다시 하고 싶게 만드는 것: 다 핀 꽃을 톡톡 누르면 5음계 음이 나고 음표·꽃잎이 흩날린다. 5송이를 다 피우면 꽃밭 축하 → "또! / 꽃 연주 / 쉬자". 다시 심으면 시간대(아침·낮·저녁)가 바뀐다.

화면으로 설명하면 (4장면):

1. 하늘에 웃는 구름 3개, 아래 꽃밭에 씨앗·새싹 5개. 구름 위에 손가락 힌트 1회. 시간대 안내 문구 1회.
2. 구름을 톡 → 빗방울이 떨어지고 새싹이 **퐁!** 하고 고개를 내민다.
3. 계속 물을 주면 줄기 **쑥!**, 봉오리 **봉긋!**, 마지막에 꽃 **팡!** + 자기 음이 울린다.
4. 다 핀 꽃을 톡톡 → 도레미솔라 연주. 5송이 모두 피면 꽃잎 축하와 소프트 엔딩.

## 4. 첫 90초

로비 카드(구름 아래 피어난 꽃) → 탭 한 번 진입 → 첫 **의미 있는** 터치(구름 톡)까지 약 2~3초.

• 막힐 수 있는 지점: "어디를 눌러야 하지?" / "꽃은 언제 눌러?"
• 막힘 완화:
  - 구름 3개는 **어느 것을 눌러도 정답**. 첫 진입 시 가운데 구름 위에 손가락 힌트가 둥실거린다.
  - 구름·꽃 터치 판정은 화면 크기와 무관하게 **지름 84px 이상**(히트 반경 42~60px). 상단 버튼도 48px 이상.
  - 물을 받으면 바로 단계별 의성어("퐁!·쑥!·봉긋!·팡!")와 성장 모션으로 다음 행동을 자연스럽게 알려 준다.
  - 다 핀 뒤에는 꽃 위에 음표(♪) 힌트가 떠서 "꽃을 누르면 소리가 난다"를 보여 준다.

## 5. 변주·질림 방지

• 변주 축 (1개): **시간대** — 아침 / 낮 / 저녁. 세션·다시 심기마다 하늘·해·잔디 톤이 바뀐다. (날씨는 구름 비가 이미 코어라 중복하지 않음)
• 발견 레이어 (1회차에 숨김, 2개):
  1. **숨은 화음** — 꽃을 **왼쪽→오른쪽(도→라)** 순서로 모두 피우면 특별 화음 + 무지개 색종이.
  2. **색종이** — 핀 꽃을 **분홍→노랑→보라(도·미·라)** 순으로 3초 안에 톡톡 누르면 색종이 샤워.
• 선택할 수 있는 것: 어떤 구름에 물을 줄지 · 어떤 꽃을 눌러 연주할지 · 피는 순서 · 멜로디 순서.
• 목표 세션 길이: **3~5분** · 루프: 꽃밭 한 바퀴 → 연주 → 다시 심기(시간대 변주) · 출구: 소프트 엔딩 + 플레이 중 `KidsKit.restButton` "쉬자"

**10회차 체크:** 물 주는 순서로 피는 순서가 달라지고, 시간대가 돌며, 숨은 화음·색종이는 우연히 만날 때까지 남는다. 저장된 꽃밭은 다시 열 때 흔들리며 반긴다.

## 6. 소프트 엔딩

질리거나 부모가 끊을 때:

• 끝나는 느낌(평가·실패 화면 없이): 5송이가 모두 피면 꽃잎 색종이가 흩날리고 "우와! 꽃밭이 활짝!" 카드가 뜬다. 점수·순위·"졌다"·제한시간 없음.
• 선택지: **또!**(꽃밭 새로 심기 + 시간대 변주) · **꽃 연주**(카드만 닫고 계속 연주) · **쉬자**(놀이터로).
• 플레이 중에도 화면 구석 **쉬자** 버튼(`KidsKit.restButton`).

## 7. 재방문 훅 (1개만)

유형: 공간 변화 + 돌봄 반김

• 한 줄: "돌아왔을 때 지난번 핀 꽃 색을 기억한 꽃밭이 살짝 흔들리며 반가워~ 한다"
• 저장: `KidsKit.store('music-garden')` 키 `garden` — 꽃별 물 양(0~8), `lastBloomColors`, `skyIndex`. 방문 횟수 `visits`. 레거시 `music-garden-v1`은 1회 마이그레이션. 발견 레이어는 라운드마다 다시 가능(영구 잠금 없음).
• 금지: 완성 압박·남과 비교·"나만의 친구" 과몰입 멘트 없음

## 8. 이번 범위 Done

**반드시 넣음 (≤3)**

1. 발견 레이어 2개(숨은 화음 · 색종이) + 꽃 터치 피드백 강화(스쿼시·이중 링·꽃잎·♬·햅틱)
2. 재방문 반김(지난 핀 꽃 색 + 흔들림) + 시간대 변주(아침/낮/저녁)
3. 이미지 슬롯 폴백(`KidsKit.assets.preload`) + 파비콘 + 쉬자 버튼 + 구상 문서·매니페스트 갱신

**다음에 미룸 (≤3)**

1. 계절·바람 캐릭터와 새 배경 소품
2. 꽃 이름·음표를 보여 주는 작은 노래 그림책
3. 꽃밭 꾸미기(울타리·화분·색 고르기)

## 9. 가드레일 점검

- [x] No Penalty · 재촉·타이머 압박 없음 (실패·게임오버·제한시간 없음, 물을 안 줘도 시들지 않음)
- [x] 터치 영역 큼직 · 즉각 피드백 (구름·꽃 히트 반경 42~60px, 상단 버튼 48px 이상)
- [x] 저자극 · 금기 소재 없음 (`docs/PROJECT.md` §6-1)
- [x] 인게임 문구는 짧은 의성어·안내만, 2~3문장 이하, 과몰입 유혹 없음
- [x] 담당 소유 카피·페르소나는 확정 범위만

**주의:** 물 준 횟수를 점수·랭킹으로 승격하지 않는다. 꽃이 피는 순서와 연주 멜로디만 즐긴다. 꽃이 다 피어도 시들지 않으며, `다시 심기`는 벌점이 아니라 새로운 놀이 시작이다.

## 10. 합의 메모

• 확정: 웹 게임(`games/music-garden/`) · 순수 HTML/CSS/JS · Canvas 2D · Web Audio API · 5음계(도레미솔라) · No Penalty · KidsKit 저장/쉬자/에셋
• 2단계 구현: 2026-11-11
• 기술 메모:
  - 꽃 5송이 = C 메이저 펜타토닉 C5·D5·E5·G5·A5
  - 구름 3개가 꽃 1~2송이씩 담당, 한 번 톡에 담당 꽃마다 빗방울 4개 → 2번 톡이면 한 송이 개화
  - 시간대 3종은 `buildBackground` 스카이·해·잔디 톤만 변경
  - 이미지 슬롯: `assets/*.webp` 없으면 코드 드로잉 폴백
  - `prefers-reduced-motion`이면 흔들림·바운스 최소화
