## 1. 한 줄 놀이

구름을 톡톡 눌러 비를 내리고, 새싹을 쑥쑥 키워 꽃을 피운 뒤 꽃을 톡톡 눌러 연주해요.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **포근한 신남 + 뿌듯 + 안심** — "내가 비를 줘서 꽃이 폈고, 꽃을 누르면 예쁜 소리가 난다."

## 3. 코어 루프 (30초~2분)

1. 아이 입력: 위쪽 구름 3개 중 하나를 손가락으로 톡.
2. 즉각 반응(시청각): 구름이 말랑하게 톡 튀며 빗방울이 통통 떨어지고, 방울마다 물소리 음이 난다.
3. 화면에 남는 변화: 빗방울을 받은 새싹이 **퐁!** → 줄기 **쑥!** → 꽃봉오리 **봉긋!** → 꽃 **팡!** 순서로 자란다. 다 핀 꽃은 도·레·미·솔·라 중 자기 음을 가진다.
4. 다시 하고 싶게 만드는 것: 다 핀 꽃을 톡톡 누르면 5음계 음이 나고 음표·꽃잎이 흩날린다. 5송이를 다 피우면 꽃밭 축하 → "또! / 꽃 연주 / 쉬자".

화면으로 설명하면 (4장면):

1. 하늘에 웃는 구름 3개, 아래 꽃밭에 씨앗·새싹 5개. 구름 위에 손가락 힌트 1회.
2. 구름을 톡 → 빗방울이 떨어지고 새싹이 **퐁!** 하고 고개를 내민다.
3. 계속 물을 주면 줄기 **쑥!**, 봉오리 **봉긋!**, 마지막에 꽃 **팡!** + 자기 음이 울린다.
4. 다 핀 꽃을 톡톡 → 도레미솔라 연주. 5송이 모두 피면 꽃잎 축하와 소프트 엔딩.

## 4. 첫 90초

로비 카드(구름 아래 피어난 꽃) → 탭 한 번 진입 → 첫 **의미 있는** 터치(구름 톡)까지 약 2~3초.

• 막힐 수 있는 지점: "어디를 눌러야 하지?" / "꽃은 언제 눌러?"
• 막힘 완화:
  - 구름 3개는 **어느 것을 눌러도 정답**. 첫 진입 시 가운데 구름 위에 손가락 힌트가 둥실거린다.
  - 구름·꽃 터치 판정은 화면 크기와 무관하게 **지름 84px 이상**(히트 반경 42~60px). 상단 버튼도 48px 이상.
  - 물을 받으면 바로 단계별 의성어("퐁!·쑥!·봉긋!·팡!")와 성장 모션으로 다음 행동을 자연스럽게 알려 준다.
  - 다 핀 뒤에는 꽃 위에 음표(♪) 힌트가 떠서 "꽃을 누르면 소리가 난다"를 보여 준다.

## 5. 변주·질림 방지

• 변주 축 (1~2개만): **꽃 5종의 음·색** / **구름 3개의 물 주는 구역**
• 발견 레이어 (1회차에 숨길 것): 꽃마다 다른 음(도·레·미·솔·라), 빗방울 소리가 꽃의 음과 맞는 것, 다 핀 순간의 화음, 꽃잎 색종이, 저장된 꽃밭.
• 선택할 수 있는 것: 어떤 구름에 물을 줄지(구름마다 1~2송이 담당) · 어떤 꽃을 눌러 연주할지 · 멜로디 순서.
• 목표 세션 길이: 3~6분 · 출구: 소프트 엔딩의 "또! / 꽃 연주 / 쉬자"

**10회차 체크:** 물 주는 순서에 따라 꽃이 피는 순서가 달라지고, 다 핀 꽃 5개로 만드는 멜로디 조합이 매번 다르다. 저장된 꽃밭은 다시 열 때도 반겨 준다.

## 6. 소프트 엔딩

질리거나 부모가 끊을 때:

• 끝나는 느낌(평가·실패 화면 없이): 5송이가 모두 피면 꽃잎 색종이가 흩날리고 "우와! 꽃밭이 활짝!" 카드가 뜬다. 점수·순위·"졌다"·제한시간 없음.
• 선택지: **또!**(꽃밭 새로 심기) · **꽃 연주**(카드만 닫고 계속 연주) · **쉬자**(놀이터로).
• (도우미 있으면) 현실·휴식 연결 멘트 방향 — §6-1 과몰입 금지 준수: v1은 **대사 없는 무언 연출**만. 도우미를 넣을 경우 확정 원고만 반영.

## 7. 재방문 훅 (1개만)

## 8. 이번 범위 Done

**반드시 넣음 (≤3)**

1. 구름 톡 → 빗방울 → 새싹 퐁 / 줄기 쑥 / 봉오리 봉긋 / 꽃 팡 성장 루프
