# 게임 구상: 숨바꼭질 공룡 친구들

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

## 1. 한 줄 놀이

숲·초원·호수에서 흔들리는 곳을 콕 누르면, 숨은 공룡이 까꿍! 하고 나타난다.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **신남 + 다정함** — "찾았다! 그리고 친구를 돌봐 주고 싶다."

## 3. 코어 루프 (30초~2분)

1. 아이 입력: 흔들리는 은신처(나무·덤불·물결 등)를 큰 터치로 콕
2. 즉각 반응(시청각): 짧은 찌그러짐 → 공룡 등장 바운스 + "까꿍!" TTS + 팡 효과음
3. 화면에 남는 변화: 찾은 수 카운트, 새 친구면 도감에 기록, 밤이면 반딧불·달빛 발견
4. 다시 하고 싶게 만드는 것: 5마리 까꿍 → 한 번 더 / 놀이터에서 먹이·씻기·놀이로 하트

화면으로 설명하면 (4장면):

1. 장소·낮/밤 고르기 → 풍경 속 은신처가 제각기 흔들림.
2. 콕! → 공룡 까꿍, 도감에 쏙.
3. 5마리 다 찾으면 부드러운 결과 → 또 하거나 놀이터.
4. 놀이터에서 먹이·씻기·놀이로 하트 채우기 → 다음에 와도 친구·도감이 남음.

## 4. 첫 90초

로비 → 타이틀 "모험 시작" → 장소 카드 탭 → 첫 은신처 탭(의미 있는 터치)까지 약 10초 이내.

• 막힐 수 있는 지점: 어디를 눌러야 하는지 모름
• 막힘 완화: 은신처만 크게 흔들림 + 힌트 필 "흔들리는 곳을 콕!" + 반짝이

## 5. 변주·질림 방지

• 변주 축 (1~2개만):
  1. **장소·시간** — 숲/초원/호수 × 낮/밤 (같은 찾기 루프, 다른 친구·풍경)
  2. **숨는 연출** — 은신처 종류별 애니(나무 뒤 삐죽·덤불 바스락·물결·둥실·살짝 흔들). 난이도↑ 없음
• 발견 레이어 (1회차에 숨길 것): 밤에만 보이는 **반딧불 톡** · **달빛 웅덩이** 반짝
• 선택할 수 있는 것: 장소 3 · 낮/밤 · 찾은 뒤 놀이터 돌봄·장식
• 목표 세션 길이: **3~5분** · 출구: 플레이 중 **쉬자**(KidsKit) / 결과에서 다른 곳·놀이터 / 소프트 엔딩

**10회차 체크:** 장소×시간 조합 + 은신처 연출 변주 + 밤 발견 요소 + 도감·하트 성장이 남아 같은 콕-까꿍이 질리지 않음.

## 6. 소프트 엔딩

질리거나 부모가 끊을 때:

• 끝나는 느낌(평가·실패 화면 없이): 5마리 결과 카드(별·응원) 유지 + 쉬자 시 KidsKit 소프트 엔딩("오늘도 까꿍 재미있었어!") → 또 할래 / 쉬자(로비)
• 현실·휴식 연결: 과몰입 유혹 없이 로비·집으로 자연스럽게

## 7. 재방문 훅 (1개만)

유형: 수집·도감 + 돌봄·관계 (기존 유지)

• 한 줄: "돌아왔을 때 만난 공룡 이름이 타이틀에서 반겨 준다"
• 저장: 기존 `dino-hide-seek-v2`(도감·하트·장식) + `KidsKit.store('dino-hide-seek')` visits
• 금지: 경쟁·랭킹·완성 압박·과몰입 유혹 없음

## 8. 이번 범위 Done

**반드시 넣음 (≤3)**

1. 은신처 종류별 숨는 연출 변주 + 찾기 연출 중 탭에도 작은 반응
2. 밤 전용 발견(반딧불·달빛) 유지·보강 + 플레이 중 쉬자·소프트 엔딩
3. 구상 문서·이미지 슬롯·KidsKit 재방문 반김 (도감·돌봄·하트 훅 유지)
