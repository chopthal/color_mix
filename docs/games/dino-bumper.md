## 1. 한 줄 놀이

공룡을 손가락으로 끌어 친구 공룡과 쿵 부딪히면, 별이 팡 터지고 열매가 통통 굴러나온다.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **신남 + 안심** — "쿵! 부딪혀도 다 같이 깔깔 웃는다."

## 3. 코어 루프 (30초~2분)

1. 아이 입력: 화면 아무 곳이나 손가락으로 끌기 (공룡 몸을 정확히 잡지 않아도 됨)
2. 즉각 반응(시청각): 공룡이 통통 따라오며 먼지 트레일 · 부딪히면 양쪽 스쿼시 바운스 + 별 파티클 + "통!" + 둘 다 깔깔
3. 화면에 남는 변화: 튀어나온 열매가 굴러다니고, 밟으면 바구니로 쏙 들어가 카운트 증가 · 아레나 소품(꽃/물결/눈가루)이 반응
4. 다시 하고 싶게 만드는 것: 5개를 모으면 황금 열매가 등장 → 둘이 같이 밀어 굴리면 색종이 엔딩 → "또!"

화면으로 설명하면 (4장면):

1. 초원 아레나, 기가노토와 스피노가 마주 봄. 손가락 아이콘 1회.
2. 끌어서 부딪힘 → 별·"통!"·둘 다 깔깔, 열매 3개가 통통 굴러나옴.
3. 열매를 밟아 바구니에 담기 → 카운트 3/5. 꽃/물결을 지나가면 소품 반응.
4. 5/5 → 황금 열매 등장 → 둘이 함께 밀기 → 색종이 → "또! / 쉬자".

## 4. 첫 90초

로비 카드(두 공룡이 쿵) → 탭 한 번 시작 → 첫 **의미 있는** 터치(첫 부딪힘)까지 약 5초.

• 막힐 수 있는 지점: 공룡이 안 움직인다고 느낌 / 상대에게 어떻게 가는지 모름
• 막힘 완화: 화면 어디를 끌어도 공룡이 따라옴 · 첫 3초 손가락 아이콘 + 상대 쪽 화살표 · 첫 충돌 전 1회만 자동으로 살짝 다가가는 유도

## 5. 변주·질림 방지

• 변주 축 (1~2개만): **아레나(바닥 마찰 + 소품)** / **공룡(특기)**
• 발견 레이어 (1회차에 숨길 것): **3번째 부딪힘마다** 숨은 리액션(엉덩방아 → 같이 점프 → 빙글 간질 순환), 아레나별 인터랙티브 소품(꽃/물결/눈가루)
• 선택할 수 있는 것: 내 공룡 8종 · 친구 공룡 8종(수동 선택/🎲 랜덤, 같은 공룡 미러 매치 허용) · 아레나 3종(초원/강가/얼음)
• 목표 세션 길이: 3~5분 · 출구: "또! / 쉬자"(플레이 중 KidsKit 쉬자 + 소프트 엔딩)

**10회차 체크:** 아레나 3 × 공룡 8 조합 + 숨은 리액션 3종 + 소품 반응 → 10회째에도 다른 조합·리액션이 남는다.

### 5-1. 공룡 로스터 (v1 8종, 전원 처음부터 선택 가능)

특기는 **추가 버튼 없이 부딪힘에 자동 발동**(만 4세 조작 부담 최소화).

| 공룡 | 특기 (패시브) |
|------|---------------|
| 기가노토사우루스 | 묵직하게 밀기 — 상대 넉백이 큼 |
| 스피노사우루스 | 물갈퀴 미끄러짐 — 부딪힌 자리에 물웅덩이, 잠깐 미끌 |
| 티라노사우루스 | 포효 — 부딪히면 "어흥" 파동, 상대가 폴짝 |
| 트리케라톱스 | 프릴 밀기 — 밀어내는 지속력이 강함 |
| 안킬로사우루스 | 통통 범퍼 — 부딪힌 상대가 더 멀리 튕김 |
| 파키케팔로사우루스 | 빠른 콩 — 이동이 가장 빠르고 튕김이 작음 |
| 브라키오사우루스 | 발쿵 — 느리지만 부딪히면 화면이 살짝 흔들리고 열매가 하나 더 |
| 테리지노사우루스 | 간지럼 — 부딪히면 상대가 깔깔 웃으며 잠깐 제자리 |

## 6. 소프트 엔딩

질리거나 부모가 끊을 때:

• 황금 열매를 함께 굴리고 색종이 → **"와아! 같이 이겼어!"**(승패 허용: 함께 기뻐하기). 점수·순위·비하 없음
• 플레이 중 **쉬자** → KidsKit softEnding("오늘도 쿵쿵 신났어!") → 또 할래 / 로비
• 과몰입 멘트 금지 (§6-1)

## 7. 재방문 훅 (1개)

유형: 수집·도감 + 돌봄·관계

• 한 줄: "돌아오면 지난번 친구 공룡이 반기고, 모은 간식 도감이 선택 화면에 보인다"
• 저장: `KidsKit.store('dino-bumper')` — 방문 수, 간식 이모지별 개수, 만난 공룡, 마지막 내/친구 공룡
• 금지: 완성 압박·남과 비교·"나만의 친구" 과몰입 멘트 없음
