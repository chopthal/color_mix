## 1. 한 줄 놀이

딸깍 브릭·컵·와플 블록을 **쌓고 끼우고**, 와르르 무너뜨려도 깔깔 웃는 놀이.

## 2. 감정 한 줄

"내가 만들었어! 무너져도 또 쌓으면 돼." — 만드는 기쁨 + 실패에 대한 안전감.

## 3. 코어 루프 (30초~2분)

1. 아이 입력: 아래 블록 트레이에서 블록을 드래그해 놓기.
2. 즉각 반응(시청각): 블록 종류별 고유 손맛 — "딸깍"(브릭), "통"(컵), "꾹"(와플) 소리 + 살짝 눌리는 모션.
3. 화면에 남는 변화: 작품이 커지고, 목표 카드(선택)의 칸이 채워짐.
4. 다시 하고 싶게 만드는 것: 완성 시 색종이 + 작품이 살아 움직임(로켓 발사, 오리 꽥꽥), 또는 와르르 연출.

화면으로 설명하면:

1. 방 고르기 — 블록 상자 3개(브릭/컵/와플) 큰 그림
2. 놀이판 + 블록 트레이 + (선택) 목표 그림 카드
3. 완성/와르르 → 정리하기

### 3-1. 블록 종류별 로직 (물리 엔진 없음)

| 방 | 블록 | 배치 규칙 | 놀이 목표(선택) | 특별 연출 |
|---|---|---|---|---|
| ① 딸깍 브릭 | 2×1, 2×2, 4×1 브릭 6색 | 정수 그리드 스냅. 바닥판 또는 다른 브릭 위에 겹치면 딸깍 결합. 공중 배치 불가(가장 가까운 지지면으로 내려앉음) | 그림 카드 따라 만들기: 집·로켓·오리(실루엣 칸 채우기) | 같은 색 5층 → 깃발 꽂힘 / 로켓 완성 → 슝 발사 |
| ② 컵 쌓기 | 엎은 컵 6색 | 규칙 기반 피라미드: 1층 슬롯 N개, 윗층 슬롯은 아래 두 컵 사이에만 활성화 (3-2-1 → 다음 판 4-3-2-1) | 피라미드 완성 | 꼭대기 컵 → 색종이 / 공 굴리기 버튼 → 와르르 → 컵 줍기(드래그로 트레이에 담기) |
| ③ 와플 블록 | 정사각 와플 판 5색 | 평면 그리드에서 상하좌우 인접 칸에만 꽂힘(꾹). 첫 판은 아무 칸 | 실루엣: 꽃·나비·자동차 | 자동차 완성 → 바퀴 굴러감 / 나비 → 날갯짓 |

- 공통: 놓은 블록을 다시 드래그해 옮기기·트레이로 돌려놓기 가능. 잘못된 곳에 놓으면 가장 가까운 유효 위치로 부드럽게 스냅(실패 표시 없음)
- 목표 카드는 선택 사항: "자유롭게" 카드가 항상 함께 있음
- 와르르(브릭·와플): 우상단 "와르르" 버튼 → 블록이 튀어 흩어졌다가 트레이로 돌아옴. 웃음 소리, 꾸중 없음
- 성능: DOM/CSS transform 기반, 블록 수 상한 40개

## 4. 첫 90초

로비 진입 → 방 고르기 생략, 1회차는 ① 딸깍 브릭 방으로 바로 → 바닥판 위 첫 칸이 반짝 + 손가락 드래그 힌트.

• 막힐 수 있는 지점: 드래그 조작, 목표 카드 의미
• 막힘 완화: 탭만 해도 블록이 다음 유효 칸에 자동 배치(탭 모드), 목표 실루엣 칸이 은은하게 깜빡

## 5. 변주·질림 방지

• 변주 축: 블록 종류(방) / 목표 그림
• 발견 레이어: 같은 색 5층 깃발, 로켓 발사, 피라미드 4단 해금(3단 1회 완성 후)
• 선택할 수 있는 것: 방, 목표 카드 vs 자유, 블록 색
• 목표 세션 길이: 4~8분 · 출구: 작품 2~3개 후 "블록 정리하자!" 제안(더 할래/쉬자)

**10회차 체크:** 방 3개 × 목표 3개 + 자유, 숨은 연출, 피라미드 단 증가.

## 6. 소프트 엔딩

• "블록 정리하자!" → 블록을 상자에 쏙쏙 드래그(또는 상자 흔들기 버튼으로 한 번에) → 뚜껑 닫힘 → "오늘도 멋지게 만들었어. 다음에 또 쌓자!"
