# 게임 구상: 뾰로롱! 변신 숨바꼭질

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

## 1. 한 줄 놀이

물건으로 뾰로롱 변신해 숨고, 이번엔 흔들리는 물건을 콕 찾아 친구를 만나요.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **두근두근 신남 + 안심** — "들켜도 까르르, 못 찾아도 까르르."

## 3. 코어 루프 (30초~2분)

1. 아이 입력: 방 안의 큰 물건 4개(소파·선물상자·곰인형·피아노) 중 하나를 콕.
2. 즉각 반응(시청각): 뾰로롱! 별가루와 함께 아이가 그 물건으로 변신, 물건이 살짝 씰룩.
3. 화면에 남는 변화: 술래 요정이 방을 걸어 다님. 내 물건 근처를 지날 때 물건이 씰룩 + "히히!" (긴장). 근처를 3번 지나가면 "못 찾겠다~" 하고 앉음.
4. 다시 하고 싶게 만드는 것: 이번엔 친구가 물건에 숨음 → 흔들리거나 ♪ 나오는 물건을 콕 → "까르르!" 친구가 폭죽처럼 튀어나옴 → 다시 숨기/찾기.

화면으로 설명하면 (4장면):

1. 거실, 물건 4개, 술래 요정 등장, 손가락 아이콘.
2. 물건 하나 콕 → 뾰로롱 변신, 물건 씰룩.
3. 술래가 근처 지나감 → "히히!" 씰룩, 술래 갸웃.
4. 술래 "못 찾겠다" → 친구가 다른 물건에 숨음 → 흔들리는 물건 콕 → 친구가 뿅.

## 4. 첫 90초

로비 카드(물건에서 삐죽 나온 얼굴) → 탭 한 번 시작 → 첫 **의미 있는** 터치(물건에 변신)까지 약 3초. 술래는 2초 뒤 문에서 등장.

• 막힐 수 있는 지점: 어느 물건에 숨지? / 찾기에서 뭘 눌러야 하지?
• 막힘 완화: **어느 물건이든 정답** · 첫 물건 하나가 반짝여 유도 · 찾기 차례엔 단서 물건이 주기적으로 흔들림+♪ · 5초 지나면 👆 힌트

## 5. 변주·질림 방지

• 변주 축 (1~2개만): **장소(거실/부엌/정원)** / **물건 세트**
• 발견 레이어 (1회차에 숨길 것): 물건마다 다른 간지럼 리액션(소파 쿠션 팡, 피아노 도레미, 곰인형 배꼽, 선물상자 리본), 술래 요정 3종의 다른 걸음/반응
• 선택할 수 있는 것: 물건 4개 중 어디에 숨을지 · 친구(술래) 3종
• 목표 세션 길이: 3~5분 · 출구: "더 할래 / 쉬자"

**10회차 체크:** 장소 3 × 물건 4 × 친구 3 × 리액션 → 10회째에도 다른 조합·리액션이 남는다. (v1은 거실 1 + 친구 3 + 리액션으로 시작)

## 6. 소프트 엔딩

질리거나 부모가 끊을 때:

• 끝나는 느낌(평가·실패 화면 없이): 둘이 나란히 만세 + 색종이, "오늘 숨바꼭질 잘했어!" 점수·순위·"졌다" 표시 없음
• (도우미 있으면) 현실·휴식 연결 멘트 방향 — §6-1 과몰입 금지 준수: v1은 **대사 없는 무언 연출**만. 도우미를 넣을 경우 확정 원고만 반영

## 7. 재방문 훅 (1개만)

유형: 돌봄·관계

• 한 줄: "돌아왔을 때 술래 요정이 나를 기억하고 손을 흔들어 반겨 준다"
• 저장 필요 여부: `localStorage` (한 번이라도 놀았는지)
• 금지: 완성 압박·남과 비교·"나만의 친구" 과몰입 멘트 없음

## 8. 이번 범위 Done

**반드시 넣음 (≤3)**

1. 숨는 차례 — 물건 4개 변신 + 술래 순찰 + 근처 씰룩/"히히!" + "못 찾겠다"
2. 찾는 차례 — 흔들림/♪ 단서 + 콕 → 친구 발견 연출 + 틀린 물건 반응(무벌점)
3. 두 차례 2라운드 반복 + 소프트 엔딩 + 로비 카드

**다음에 미룸 (≤3)**

1. 장소 변주(부엌/정원)
2. 술래 요정 3종 + 재방문 인사(`localStorage`)
3. 물건 추가(침대·책장 등)

## 9. 조작 (확정: A)

물건·단서를 **콕** 탭한다. 4세에 가장 단순하고 미스·실패가 없다. 원안의 "통! 박치기"는 드래그 충돌 미스가 생기기 쉬워 v1에서는 탭으로 단순화했다.

- 숨는 차례: 물건을 콕 → 변신. 술래는 숨은 물건과 가장 가까운 순찰 지점부터 향해 초반에 "히히!"를 보여 준다.
- 숨는 차례 길이: 약 6.5초 뒤 술래가 "?" 하며 포기 → 찾는 차례.
- 찾는 차례: 친구가 숨은 물건 위에 **♪가 계속 떠 있고** 주기적으로 흔들린다. 콕 맞히면 "까르르!", 틀려도 벌점 없이 계속 찾는다.
