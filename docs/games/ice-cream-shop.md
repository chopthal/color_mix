## 1. 한 줄 놀이

동물 손님이 말한 **개수만큼** 아이스크림 스쿱을 콘 위에 **하나, 둘, 셋** 쌓아 건네는 놀이.

## 2. 감정 한 줄

"내가 세어서 딱 맞게 줬더니 손님이 좋아했어!" — 셀 수 있다는 뿌듯함.

## 3. 코어 루프 (30초~1분)

1. 아이 입력: 맛 통(딸기·초코·바닐라·민트·블루베리)을 콕 → 스쿱이 콘 위로 톡 올라감.
2. 즉각 반응(시청각): 스쿱마다 음성 "하나!", "둘!" + 뽁 소리, 콘 옆 개수 점(●)이 하나씩 채워짐.
3. 화면에 남는 변화: 콘 위 탑이 높아지고, 다 맞으면 "건네기" 버튼(큰 손 아이콘)이 반짝.
4. 다시 하고 싶게 만드는 것: 손님이 할짝할짝 먹으며 하트 → 다음 손님 입장.

화면으로 설명하면:

1. 가게 카운터 + 손님 + 말풍선(맛 그림 × 개수)
2. 맛 통 터치 → 콘 위 스쿱 쌓기 (음성 세기)
3. 건네기 → 손님 냠냠 하트 → 다음 손님

### 3-1. 핵심 로직

- 상태: `order` → `scoop` → `serve` → `eat` → (손님 5명 미만이면 `order` / 아니면 `ending`)
- 주문 생성
  - 1단계(손님 1~2번째): 한 가지 맛 × 1~3개
  - 2단계(3번째~): 두 가지 맛 합계 2~5개 (예: 딸기 2 + 초코 1)
- 말풍선: 맛 색 원 아이콘을 개수만큼 나열 + 음성 "딸기 두 개 주세요!" (TTS, 오프라인 폴백은 그림만으로 충분해야 함)
- 판정(건네기 시)
  - 딱 맞음 → 큰 기쁨 + 별 반짝
  - 모자람 → 손님 "음, 하나 더 먹고 싶어!" (해당 맛 통이 살짝 깜빡) — 실패 화면 없음
  - 많음 → "와, 덤이다! 고마워!" 로 그대로 성공 처리
  - 맛이 다름 → "오, 이 맛도 좋아!" 성공 처리(맛보다 개수가 학습 축)
- 스캐폴딩: 8초 무입력 → 말풍선 아이콘이 하나씩 통통 튀며 세어 줌 → 15초 → 필요한 맛 통이 반짝
- 되돌리기: 콘 맨 위 스쿱을 위로 쓸면 통으로 돌아감 ("하나 빼기")

## 4. 첫 90초

로비 진입 → 첫 손님이 바로 들어와 "바닐라 하나 주세요!" → 바닐라 통이 반짝(1회차만 자동 유도).

• 막힐 수 있는 지점: 건네기 버튼을 모름
• 막힘 완화: 개수가 맞으면 건네기 버튼이 커지며 손가락 힌트 애니메이션

## 5. 변주·질림 방지

• 변주 축: 손님 동물(펭귄·곰·토끼·고양이) / 맛 색
• 발견 레이어: 7개 이상 쌓으면 탑이 흔들흔들 → 손님이 혀로 받아먹는 연출 / 가끔(10%) 무지개맛 통 등장
• 선택할 수 있는 것: 주문과 다른 맛을 줘도 성공, 마지막 손님은 "아무거나 좋아!"(자유 쌓기)
• 목표 세션 길이: 4~6분(손님 5명) · 출구: 엔딩에서 "더 할래 / 쉬자"

**10회차 체크:** 손님 순서·주문 조합 랜덤, 단골 손님의 "지난번 그 맛" 주문, 무지개맛.

## 6. 소프트 엔딩

• 손님 5명 후 가게 셔터가 스르르 → 오늘 받은 손님들이 창밖에서 손 흔듦 → "오늘 장사 끝! 다음에 또 와!"
• 쉬자: "우리도 시원한 물 한 잔 마시고 쉬자"
