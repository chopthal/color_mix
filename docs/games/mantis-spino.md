`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

## 1. 한 줄 놀이

사마귀나 스피노를 골라 커다란 버튼을 누르면, 둘이 마주 보고 "째깍!" "크아앙!" 장난으로 겨루고 별이 팡 터지며 깔깔 웃는다.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **신남 + 안심** — "마음껏 겨뤄도 아무도 안 아프고, 끝나면 하이파이브."

## 3. 코어 루프 (30초~2분)

1. 아이 입력: 캐릭터별 공격 버튼 3개 중 하나 탭
2. 즉각 반응(시청각): 캐릭터마다 커스텀 기술 — 외침(소리 물결)·돌진(물기/밀기)·폴짝·물 뿌리기 등 + 의성어 효과음
3. 화면에 남는 변화: 상대가 "폭신!" 빙글 휘청 + 별·하트·거품 팡 → 맞은 쪽은 웃음(간질간질) (피·통증·찡그림 없음)
4. 다시 하고 싶게 만드는 것: 상대가 매번 3기술 중 하나로 랜덤 반격 → 내 캐릭터도 폭신 빙글 → 3번 겨룬 뒤 하이파이브 → 색종이 → "또! / 쉬자"

화면으로 설명하면 (4장면):

1. 두 캐릭터가 마주 보고 "으르렁~"(귀여운 소리). 큼직한 공격 버튼 1개.
2. 버튼 탭 → 내 캐릭터 공격 → 상대 "폭신!" 빙글 + 별·하트·거품 팡.
3. 상대가 자동 반격 → 내 캐릭터도 폭신 빙글 + 웃음.
4. 3번 겨룬 뒤 하이파이브 → 색종이 → "또! / 쉬자".

## 4. 첫 90초

로비 카드(사마귀·스피노가 마주 봄) → 탭 한 번 → 내 캐릭터 2장 고르기 → 시작 → 첫 공격까지 약 8초.

• 막힐 수 있는 지점: 뭘 눌러야 할지 모름 / 공격이 먹혔는지 모름
• 막힘 완화: 버튼 큼직 + 첫 3초 반짝임 유도 · 공격 즉시 큰 반응(폭신+별+소리)으로 "먹혔다"가 보임 · 대치 중 "으르렁~" 후 버튼만 빛남

## 5. 변주·질림 방지

• 변주 축 (1~2개만): **내/적 캐릭터 조합(11종 풀)** / 배경(미룸)
• 발견 레이어 (1회차에 숨길 것): 3번째 겨루기마다 숨은 리액션(둘 다 엉덩방아, 같이 웃음)
• 선택할 수 있는 것: 내 친구·적 친구 모두 11종(동물·공룡·곤충)에서 각각 선택(같은 캐릭터 미러 허용), 캐릭터별 공격 3종 중 선택
• 목표 세션 길이: 3~5분 · 출구: "더 할래(또!) / 쉬자"

**10회차 체크:** 내/적 11×11 조합 + 숨은 리액션 → 같은 루프 10번에도 매번 다른 조합·새로움이 남는다.

## 6. 소프트 엔딩

질리거나 부모가 끊을 때:

• 끝나는 느낌(평가·실패 화면 없음): 3번 겨룬 뒤 하이파이브 → 색종이 → "또! / 쉬자". 점수·순위·"졌다" 표시 없음
• (도우미 있으면) 현실·휴식 연결 멘트 방향 — §6-1 과몰입 금지 준수: v1은 **대사 없는 무언 연출**. 도우미를 넣을 경우 "그만~ 쉬자"로 현실·간식 연결

## C. 렌더링 (canvas) — 재사용 지침

**구현 확정:** 캐릭터 11종을 파라미터형 `drawCritter(ctx, ch, x, y, r, {art 플래그})` 단일 함수로 통합 구현했다. 아래 재사용 지침은 대안 기록.

- 공룡 3종 + 스피노: `dino-bumper/js/game.js`의 `drawDino` 로직을 그대로 가져와 쓴다(몸통·돛·뿔·목 그리는 부분). 스쿼시/바운스(`squash`)도 재사용.
- 사마귀 + 동물 3 + 곤충 3: `drawDino`의 몸통(타원) + 눈 + 볼터치 골격을 따라, 각 `art` 플래그에 대응하는 특징(낫/갈기/코/귀/턱/뿔/점)을 **둥글둥글하게** 추가한다. 새 특징은 날카로운 모서리 없이 둥근 모양으로 그린다.
- **무기 무해화 렌더 규칙:** 이빨·낫·뿔·턱은 실제 날카로움이 아닌 **둥근 마시멜로/솜/거품** 모양(곡선·연한 채도). 공격 모션은 몸이 앞으로 0.2초 `lunge`(scaleX 늘임) 후 복귀.

## D. 상태 머신 (대결 흐름) — `js/game.js`

```
select(내 캐릭터 2장 중 탭 → 시작)
  → faceOff: 양 캐릭터 마주 봄 + "으르렁~"(0.8초) → 공격 버튼 활성+반짝
  → playerAttack: 버튼 탭 → 내 캐릭터 lunge + 무기 + 의성어 → 상대 폭신 반응(빙글 휘청 + 별·하트·거품 파티클 + 웃음) (1초)
  → enemyAttack: 상대 자동 lunge 반격 → 내 캐릭터 폭신 반응 (1초)
  → (공격+반격 = 1겨루기) 3번 반복
  → highFive: 두 캐릭터 하이파이브 + 색종이 → 오버레이 "또! / 쉬자"
  → 또! → 상대 메이트 9종 중 랜덤 교체 → faceOff부터
  → 쉬자 → 로비(`../../index.html`)
```

- 버튼은 화면 하단에 큼직(최소 64px), 공격 가능할 때만 반짝. 그 외 시간 탭은 무시(무벌점).
- 공격 중/반격 중 연속 탭은 무시(과몰입·연타 방지, 무벌점).
- 3번째 겨루기의 폭신 반응 때 숨은 리액션: 둘 다 엉덩방아 + 함께 웃음.

## E. 효과음 — `js/sound.js`

`star-candy/js/sound.js` 구조(Web Audio, `resume` 처리) 재사용. 함수와 목표 느낌:

| 함수 | 느낌 | 구현 힌트 |
|------|------|-----------|
| 대치 `playGrowl` | 귀여운 "으르렁~" | 저음 sawtooth 짧게 + 볼륨 작게 |
| 공격 `playAttack(sound)` | 캐릭터별 의성어 | 짧은 chirp·thump (물기=낮게, 낫=높게) |
| 폭신 `playPoof` | "폭신" | 저음 sine thump + 짧은 노이즈 |
| 웃음 `playLaugh` | "간질간질" | 짧은 상승 chirp 2~3연타 |
| 하이파이브 `playHighfive` | "짝!" | 짧은 noise burst |

- 전체 음량 낮게, 날카로운 고음·과도한 번쩍임 없음. 사운드 토글 버튼(🔊) 유지.
