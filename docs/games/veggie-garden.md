## 1. 한 줄 놀이

씨앗을 심고 물 주면 쑥쑥 자라고, **쑥!** 뽑아 창고에 쌓아 두었다가, 부엌에서 요리해 동물 친구와 **냠냠** 먹는 놀이.

## 2. 감정 한 줄

"내가 키운 채소로 만든 걸 친구가 먹었어!" — 기르고 나누는 뿌듯함.

## 3. 코어 루프 (1~2분)

1. 아이 입력: 밭 칸 콕(씨앗 심기) → 물뿌리개 드래그로 쓱쓱 → 다 자란 작물을 위로 쓸어 뽑기.
2. 즉각 반응(시청각): 물방울·반짝, 씨앗 → 싹 → 잎 → 열매 3단 성장 애니메이션, 뽑을 때 "쑥!" + 흙 튐.
3. 화면에 남는 변화: 뽑은 작물이 바구니 → 창고 선반으로 통통 튀어 쌓임(선반 칸이 채워짐).
4. 다시 하고 싶게 만드는 것: 창고 재료로 요리 → 동물 친구 냠냠 하트 → 처음 만든 요리는 "새 요리!" 그림 카드.

화면으로 설명하면 (3장면, 하단 큰 탭 아이콘 3개로 오감):

1. **밭** — 2×3 밭 칸, 씨앗 주머니, 물뿌리개
2. **창고** — 나무 선반, 작물별 칸에 쌓인 채소(개수만큼 그림)
3. **부엌** — 요리 도구 + 기다리는 동물 친구

### 3-1. 핵심 로직

- 작물(이번 범위 3종): 당근(주황), 토마토(빨강), 옥수수(노랑)
- 성장: 칸별 stage 0(빈칸)→1(씨앗)→2(싹)→3(잎)→4(수확 가능)
  - 물 주기 1회 = stage +1 (세션 내 빠른 성장, 기다림 강요 없음)
  - 재방문 시: 저장된 stage가 1 이상인 칸은 +1 자라 있음(최대 4) — 시들기·죽음 없음
- 수확: stage 4에서 위로 쓸기(또는 길게 누르기) → 창고 inventory[crop] += 1 (2~3개 랜덤, 왕호박류 발견 레이어는 1회 보너스)
- 창고: inventory 표시, 작물 그림을 개수만큼 쌓아 보여 줌(최대 표시 10, 초과는 "가득!" 반짝)
- 부엌 도구 (forest-soup 냄비와 겹치지 않게):
  - **믹서**: 재료 1~3개 넣기 → 큰 버튼 꾹 누르는 동안 윙윙 → 재료 색을 섞은 주스(색 혼합 = 평균 RGB)
  - **샐러드 볼**: 재료 2~3개 넣기 → 손가락으로 뱅글 저어 진행 링 채우기 → 알록달록 샐러드
- 요리 완성 → 동물 친구(토끼·다람쥐·곰 순환)가 냠냠 → 하트. 재료 조합 키로 "처음 본 요리" 판정 → 요리 카드 해금
- 창고가 비었을 때 부엌 진입: 친구가 "밭에 가 볼까?" + 밭 탭 반짝(꾸중 없음)

## 4. 첫 90초

로비 진입 → 밭 화면, 한 칸에 이미 싹이 나 있고 물뿌리개가 반짝 → 쓱쓱 → 바로 열매 → 뽑기 손가락 힌트.

• 막힐 수 있는 지점: 뽑기 제스처, 장면 이동
• 막힘 완화: 1회차는 다 자란 작물을 콕만 해도 뽑힘. 첫 수확 후 창고 탭이 반짝 → 창고 후 부엌 탭이 반짝(자동 유도)

## 5. 변주·질림 방지

• 변주 축: 씨앗 종류 / (다음 범위) 날씨
• 발견 레이어: 가끔 지렁이 친구가 흙에서 까꿍, 3% 확률 왕당근(뽑을 때 줄다리기 연출), 새 요리 카드
• 선택할 수 있는 것: 어느 칸에 무엇을 심을지, 어떤 재료로 무슨 도구를 쓸지
• 목표 세션 길이: 5~8분 · 출구: 요리 3번 후 "다 같이 배불러!" 엔딩 제안(더 할래/쉬자)

**10회차 체크:** 재방문마다 자라 있는 밭, 아직 못 본 요리 카드, 지렁이·왕당근.

## 6. 소프트 엔딩
