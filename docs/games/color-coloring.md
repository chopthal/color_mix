## 1. 한 줄 놀이

도감에서 그림을 고르고, 물감·무늬·스티커로 알록달록 칠한 뒤 낮·밤·무지개 무대에 작품을 걸어 두는 색칠 놀이.

## 2. 감정 한 줄

내가 고른 색으로 그림이 예뻐지는 **뿌듯함** + 무대 날씨가 바뀌는 **작은 신남** + 돌아왔을 때 내 액자가 반겨 주는 **따뜻함**.

## 3. 코어 루프 (30초~2분)

1. 아이 입력: 도감 카드 콕 → 물감(또는 무늬·스티커) 고르기 → 파트 콕/문지르기. 원하면 🌈로 무대(낮/밤/무지개) 바꾸기.
2. 즉각 반응(시청각): 파트가 통통 물들고 톡 소리, 테마 전환 시 날씨 파티클·짧은 멘트.
3. 화면에 남는 변화: 칠해진 파트·스티커·무대 테마. 전부 칠하면 축하 + 도감 ⭐ + (자동) 갤러리 1장.
4. 다시 하고 싶게 만드는 것: 다른 그림·다른 날씨·내가 만든 색·갤러리 불러오기.

화면으로 설명하면 (4장면):

1. 도감 그리드(카테고리 탭). 재방문이면 상단에 **최근 작품 액자**가 반김.
2. 색칠 무대: 가운데 그림, 아래 물감/무늬/스티커, 위 🌈 테마·저장·갤러리.
3. 다 칠함 → 색종이 + “완성!” → 도감에 ⭐. 세션에서 몇 장 칠하면 소프트 엔딩.
4. 갤러리/액자로 다시 열어 꾸미기.

## 4. 첫 90초

로비 → 도감 → 아무 카드 탭 → 첫 파트 칠하기까지 목표 **10초 이내**.

• 막힐 수 있는 지점: “어디를 칠하지?” / “배경 버튼이 뭘까?”
• 막힘 완화: 파트 전체가 큼직·기본 크림색; 첫 색칠 진입 시 테마 버튼이 살짝 퐁퐁; 마법붓(🪄)으로 빈 파트 한 번에 채우기 가능(이미 다 칠했으면 부드러운 안내음).

## 5. 변주·질림 방지

• 변주 축 (1~2개만):
  1. **배경·날씨 무대** — 낮 / 밤 / 무지개 (아이 눈높이로 장식·파티클·뱃지·짧은 멘트 강화)
  2. **도감 50종 + 물감·무늬·스티커·색 섞기** (기존 축 유지)
• 발견 레이어: 무지개 무대·마법붓·색 섞기 미션(“정답이야” 유지)·갤러리 액자 반김
• 선택할 수 있는 것: 그림 / 색·무늬·스티커 / 무대 날씨
• 목표 세션 길이: **3~5분** · 출구: KidsKit **또 할래 / 쉬자** + 상시 **쉬자**

**10회차 체크:** 매회 다른 그림·날씨·내가 만든 색·스티커 배치가 달라지고, 돌아보면 최근 작품 액자가 반긴다.

## 6. 소프트 엔딩

• 한 세션에서 **완성 3장**이면 `KidsKit.softEnding` (“오늘도 잘 칠했어!” + 또 할래 / 쉬자). 실패·점수 없음.
• 언제든 `KidsKit.restButton`(쉬자) → 로비.
• 과몰입 멘트 없음. 휴식·현실 연결만.

유형: 수집·도감

## 10. 이미지 슬롯 설계 (대표 20종)

### 방식: 선화(outline) 이미지 + 기존 SVG 파트 마스크

색칠 파트 히트/채우기는 **기존 SVG `class="part" data-part`** 가 담당한다.  
대표 20종만 `games/color-coloring/assets/<id>-outline.webp` 가 있으면:

1. 아래층: SVG 파트(채색·터치). outline 모드에서는 파트 **stroke를 숨기고** fill만 보이게 해 선화가 윤곽을 맡는다. `.fixed`/얼굴 고정선도 SVG 쪽은 숨김(선화에 포함될 전제).
2. 위층: 선화 WebP(`pointer-events: none`, contain). 알파 밖은 투명.
3. 파일 없음·로드 실패: **현재와 동일하게 SVG만** 그림(폴백).
4. 런타임 로드 게이트: `games/color-coloring/assets/slots.json`의 `ready: string[]`에 키가 있을 때만 `KidsKit.assets.preload`한다.  
   (파일이 아직 없을 때 404 콘솔 소음을 막기 위함. 이미지 생성 후 해당 키를 `ready`에 추가.)

나머지 30종은 SVG 전용(슬롯·매니페스트 없음).
