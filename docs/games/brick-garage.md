# 게임 구상: 철컥철컥! 브릭 특장차 차고

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

• 경로: `games/brick-garage/`
• 상태: 합의됨 · 1차 구현 완료(58종 도감·자유 조립·출동 5종·스페셜 파츠 3종)
• 갱신: 2026-10-30

---

## 1. 한 줄 놀이

블록을 철컥철컥 끼워 특장차를 만들고, 블록 도시를 부순다.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **뿌듯함 + 신남**

## 3. 코어 루프 (30초~60초)

1. 아이 입력: 컨베이어에 나온 브릭을 탭
2. 즉각 반응(시청각): 브릭이 실루엣으로 날아가 "철컥" + 바운스
3. 화면에 남는 변화: 차체에 브릭이 하나씩 쌓여 차가 완성됨
4. 다시 하고 싶게 만드는 것: 완성 연출(사이렌 점멸·피규어 인사) → 출동해서 차량별 미션

화면으로 설명하면 (2~4장면):

1. 설계도 카드 고르기 (58종 · 6 카테고리 탭)
2. 브릭 탭 → 철컥 조립 (브릭 5개)
3. 완성! 차가 살아 움직임 → "출동!" 버튼
4. 블록 도시에서 미션(바위·물·다리·길 메우기·미니카 싣기) → 차고 선반에 진열

## 4. 첫 90초

로비 진입 → 첫 **의미 있는** 터치까지:

• 막힐 수 있는 지점: 설계도 선택에서 고민, 조립에서 드래그를 기대
• 막힘 완화(힌트·더 큰 터치·자동 유도): 카드 전체가 터치 영역. 드래그 없이 **탭 한 번**으로 스냅. 6초 무반응 시 브릭 깜빡 + 손가락 힌트

## 5. 변주·질림 방지

• 변주 축 (1~2개만): **차량 종류**(58종 · 소방·경찰·구조·중장비·환경·운송 6 카테고리) + 차량별 미션
• 발견 레이어 (1회차에 숨길 것): 완성 시 예상 못한 리액션(피규어 손 흔들기, 사이렌 점멸)
• 선택할 수 있는 것: 바퀴(보통/몬스터/제트), 설계도 58종, **자유 조립**(하판·운전석·기믹·사이렌·바퀴 교체, 차체 도색 6색, 섞기) + 해금 시 스페셜 파츠
• 목표 세션 길이: 3~5분 · 출구("더 할래 / 쉬자"): 완성 후 "차고로" 버튼

**10회차 체크:** 같은 루프 10번 때 아직 남는 작은 새로움: 다른 차량의 기믹 브릭 모양·색, 바퀴 선택, 부수는 바위 색 조합

## 6. 소프트 엔딩

질리거나 부모가 끊을 때:

• 끝나는 느낌(평가·실패 화면 없이): "출동 성공!" 후 조용히 차고로. 실패·게임오버 없음
• (도우미 있으면) 현실·휴식 연결 멘트 방향 — §6-1 과몰입 금지 준수: 1차에는 대사 없음(효과음·아이콘만). 도우미는 후속 합의

## 7. 재방문 훅 (1개만)

유형: 수집·도감 (내 차고 선반)

• 한 줄: "돌아왔을 때 **내가 만든 차들**이 선반에서 반겨 준다"
• 저장 필요 여부: localStorage (`kids_brick_garage_v1`)
• 금지: 경쟁·랭킹·완성 압박·과몰입 유혹

## 8. 이번 범위 Done

**반드시 넣음 (≤3)**

1. 설계도 58종(6 카테고리 탭) 조립 + **자유 조립**(하판·운전석·기믹·사이렌·바퀴 탭 교체, 차체 도색 6색, 섞기, 저장 없이 바로 출동, 선반 저장)
