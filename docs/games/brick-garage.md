# 게임 구상: 철컥철컥! 브릭 특장차 차고

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

• 경로: `games/brick-garage/`
• 상태: 합의됨 · 2단계 고도화(세차·도감 흡수·미션 변주·재방문 반김)
• 갱신: 2026-11-11

---

## 1. 한 줄 놀이

블록을 철컥철컥 끼워 특장차를 만들고, 출동·세차하고, 열린 차고에서 차를 구경한다.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **뿌듯함 + 신남**

## 3. 코어 루프 (목표 호흡 약 1~2분 × 2~3회 = 3~5분)

1. 아이 입력: 설계도/오늘의 출동 카드 탭 → 브릭 탭 조립
2. 즉각 반응: 철컥 스냅 + 완성 사이렌 → 출동 미션 타깃 탭
3. 화면에 남는 변화: 선반에 차 진열 → 세차 후 반짝 → 도감에서 음성 소개
4. 다시 하고 싶게: 다른 차·다른 배경 미션·오늘 반기는 차

화면 흐름:

1. 설계도 / 오늘의 출동 1장
2. 조립 → 출동(장소·타깃 세트 로테이션)
3. 세차(비누→물→바람→반짝)
4. 선반 반김 / 열린 도감(잠금 없음)

## 4. 첫 90초

• 막힘 완화: 카드·브릭 탭만, 드래그 없음. 6초 무반응 힌트 유지
• 오늘의 출동 카드로 첫 선택을 더 빠르게

## 5. 변주·질림 방지

• **변주 축:** (1) 차량 종류·실루엣/트림 색 변별 (2) 같은 미션의 배경·타깃 세트 로테이션
• **발견 레이어:** 완성 사이렌·피규어, 세차 반짝, 스페셜 파츠 해금
• **선택:** 58종 설계도 + 자유 조립 + 열린 도감
• **세션:** 3~5분 · 출구: KidsKit `restButton` + 소프트 엔딩(또 할래/쉬자)

**10회차 체크:** 다른 차 실루엣, 미션 배경(낮/노을/공원), 오늘 반기는 차

## 6. 소프트 엔딩

• 세차 후 또는 차고 복귀 시 세션 루프 ≥2이면 `KidsKit.softEnding`
• 실패·점수·게임오버 없음

## 7. 재방문 훅 (1개)

유형: 돌봄·관계 + 수집

• 한 줄: "돌아왔을 때 **오늘 반기는 차 1대**가 선반에서 손을 흔든다"
• 저장: `localStorage` (`kids_brick_garage_v1`) + `KidsKit.store('brick-garage')`
• 금지: 잠금 46대·별 도장 압박·경쟁

## 8. 이번 범위 Done

1. special-vehicles **세차·도감(음성 소개)** 을 brick-garage 서브모드로 이식(열린 차고, 잠금/별 UI 없음) + 오늘의 출동 1장
2. 차종 **실루엣/트림 변별** + 출동 **장소·타깃 로테이션** + 선반 **오늘 반기는 차**
