# 게임 구상: 반짝반짝 별사탕을 지켜요

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

• 경로: `games/star-candy/`
• 상태: Done (2단계 고도화)
• 갱신: 2026-11-11

---

## 1. 한 줄 놀이

상자에 별사탕을 콕 숨기고, 다가오는 요정 친구를 **끌어다 콩!** 밀어내요.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **짓궂은 신남 + 뿌듯 + 안심** — "내가 지켰다! 콩 하고 밀어도 둘 다 깔깔 웃는다. 요정이 가져가도 축하하고 다시 숨긴다."

## 3. 코어 루프 (30초~2분)

1. 아이 입력: 화면의 큰 상자 5개 중 하나를 손가락으로 콕.
2. 즉각 반응(시청각): 별사탕이 반짝이며 상자에 쏙, "반짝!" + 상자가 씰룩.
3. 화면에 남는 변화: 요정이 다가옴 → 아이 캐릭터를 끌어 **콩!** → 비눗방울 / 엉덩방아 / 폭죽 중 하나가 로테이션으로 연출. 5콩마다 스티커 1장·장소 전환.
4. 다시 하고 싶게 만드는 것: 요정이 다시 다가옴 / 상자를 열어도 "요정 축하해!" 후 다시 숨기기 / 세션 안 장소 변주·스티커 수집.

화면으로 설명하면 (4장면):

1. 밤 보물방(또는 별 정원)에 큰 상자 5개, 별사탕이 반짝. 손가락 아이콘 1회.
2. 상자 하나를 콕 → 사탕이 쏙 ("반짝!").
3. 요정이 다가옴 → 끌어 콩! → 띠용~/통통!/팡팡! 중 하나.
4. 3라운드 지키면 소프트 엔딩 · "또! / 쉬자".

## 4. 첫 90초

로비 카드 → 요정 고르기 → 첫 **의미 있는** 터치(상자에 숨기기)까지 약 3~8초.

• 막힐 수 있는 지점: 어느 상자에 넣지? / 어떻게 밀지?
• 막힘 완화: **어느 상자든 정답** · 첫 상자 유도 👆 · 첫 요정 접근 ~3초 무드래그 시 화살표+손가락 · 화면 아무 곳이나 끌어도 아이 캐릭터가 따라옴

## 5. 변주·질림 방지

• 변주 축 (1~2개): **장소**(별 보물방 / 별사탕 정원) · **콩 연출**(비눗방울·엉덩방아·폭죽 로테이션)
• 발견 레이어: 콩마다 다른 리액션 문구·연출 / 라운드마다 장소 전환 / 스티커 순서 해금
• 선택할 수 있는 것: 상자 5개 · 요정 3종
• 목표 세션 길이: **3~5분**(라운드×3 ≈ 같은 루프를 여러 번) · 출구: 소프트 엔딩 + KidsKit 쉬자 + 상단 놀이터

**10회차 체크:** 요정 3종 × 장소 2종 × 콩 리액션 3종 × 스티커 5칸 → 조합이 남는다.

### 5-1. 조작 (확정: A)

아이 캐릭터를 손가락으로 끌어 요정에 콩. **잡고 있으면** 닿는 순간 발동(이동 속도 조건 없음).

- 요정 접근 속도: `clamp(min(W,H) × 0.4, 150, 320)` px/s
- 한 번 콩! 후 요정은 선택된 연출로 밀려났다가 문으로 돌아가 다시 다가온다.

### 5-2. transform-hide와 방 톤 분리

| | star-candy (지키기·드래그) | transform-hide (탭 변신) |
|--|--|--|
| 분위기 | 밤 보물방 / 별 정원 | 낮 민트 거실 |
| 창문 | 둥근 달 창 | 사각 낮 창 |
| 문 | 사각 요새 문 + 캔디케인 틀 | 아치 문 |
| 소품 | 사탕 단지 / 별 덤불 | 화분 |
| 바닥 | 보라·숲톤 + 별 러그 | 나무색 + 살구 러그 |

캐릭터 에셋 계열은 공유 가능하나 **방 배경·소품 톤은 분리**한다. `games/transform-hide`는 이 게임에서 수정하지 않는다.

## 6. 소프트 엔딩

• 세션 3라운드 지키기 성공 후: "오늘 별사탕 잘 지켰어!" + 모은 스티커 · **또!** / **요정 바꾸기** / **쉬자**
• 플레이 중 언제든 KidsKit **쉬자** 버튼 → 로비
• 점수·순위·"졌다" 패널티 화면 없음. 요정이 사탕을 가져가도 축하 후 다시 숨기기
