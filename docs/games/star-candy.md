# 게임 구상: 반짝반짝 별사탕을 지켜요

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

• 경로: `games/star-candy/`
• 상태: Done (이번 범위)
• 갱신: 2026-10-31

---

## 1. 한 줄 놀이

상자에 별사탕을 콕 숨기고, 다가오는 요정 친구를 콩! 밀어내요.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **짓궂은 신남 + 뿌듯 + 안심** — "내가 지켰다! 콩 하고 밀어도 둘 다 깔깔 웃는다."

## 3. 코어 루프 (30초~2분)

1. 아이 입력: 화면의 큰 상자 5개 중 하나를 손가락으로 콕.
2. 즉각 반응(시청각): 별사탕이 반짝이며 상자에 쏙, "반짝!" + 상자가 씰룩.
3. 화면에 남는 변화: 새침한 요정 친구가 상자 쪽으로 걸어옴 → 아이 캐릭터를 끌어 **콩!** 밀면 요정이 비눗방울/엉덩방아로 둥실, 상자에 반짝 표시가 남음.
4. 다시 하고 싶게 만드는 것: 요정이 툴툴 털고 다시 다가옴 → 몇 번이고 콩! / 놓쳐 상자를 열어도 "앗 잡았다!" 웃고 다시 숨기기 → 자연 반복.

화면으로 설명하면 (4장면):

1. 방 안에 큰 상자 5개, 별사탕이 반짝. 손가락 아이콘 1회.
2. 상자 하나를 콕 → 사탕이 쏙, 상자가 씰룩 ("반짝!").
3. 요정이 다가옴 → 아이 캐릭터를 끌어 콩! → 요정이 비눗방울에 둥실 ("띠용~").
4. 요정이 다시 다가옴 → 반복 → "더 할래 / 쉬자" 출구.

## 4. 첫 90초

로비 카드(상자에서 삐죽 나온 사탕) → 탭 한 번 시작 → 첫 **의미 있는** 터치(상자에 숨기기)까지 약 3초.

• 막힐 수 있는 지점: 어느 상자에 넣지? / 어떻게 밀지?
• 막힘 완화: **어느 상자든 정답**(빈 상자 없음) · 첫 상자 하나가 살짝 반짝여 유도 · 첫 요정 접근 때 화살표 + 손가락 아이콘 1회 · 화면 아무 곳이나 끌어도 아이 캐릭터가 따라옴

## 5. 변주·질림 방지

• 변주 축 (1~2개만): **요정 캐릭터** / **상자 모양·색**
• 발견 레이어 (1회차에 숨길 것): 3번째 콩마다 다른 리액션(비눗방울·엉덩방아·폭죽), 상자마다 숨은 그림(고양이·음표·하트)
• 선택할 수 있는 것: 상자 5개 중 어디에 숨길지 · 요정 친구 3종
• 목표 세션 길이: 3~5분 · 출구: "더 할래 / 쉬자"

**10회차 체크:** 요정 3종 × 상자 숨은 그림 × 콩 리액션 3종 → 10회째에도 다른 조합·리액션이 남는다.

### 5-1. 조작 (확정: A)

아이 캐릭터를 손가락으로 끌어 요정에 콩. **손가락으로 잡고 있으면** 요정이 몸에 닿는 순간 발동한다(이동 속도 조건 없음). 놓으면 요정이 상자를 열 수 있고, 열려도 벌점 없이 다시 숨기면 된다.

- 요정 접근 속도: `clamp(min(W,H) × 0.4, 150, 320)` px/s — 세로 화면에서도 너무 느리지 않게.
- 한 번 콩! 후 요정은 비눗방울/엉덩방아로 밀려났다가 문으로 돌아가 다시 다가온다.

## 6. 소프트 엔딩

질리거나 부모가 끊을 때:

• 끝나는 느낌(평가·실패 화면 없이): 요정과 아이가 나란히 만세 + 색종이, "오늘 별사탕 잘 지켰어!" 점수·순위·"졌다" 표시 없음
• (도우미 있으면) 현실·휴식 연결 멘트 방향 — §6-1 과몰입 금지 준수: v1은 **대사 없는 무언 연출**만. 도우미를 넣을 경우 확정 원고만 반영

## 7. 재방문 훅 (1개만)

유형: 수집·도감

• 한 줄: "돌아왔을 때 지킨 별사탕 스티커가 도감에 반겨 준다"
• 저장 필요 여부: `localStorage` (지킨 별사탕 스티커)
• 금지: 완성 압박·남과 비교·"나만의 친구" 과몰입 멘트 없음

## 8. 이번 범위 Done

**반드시 넣음 (≤3)**

1. 상자 5개 숨기기 → 요정 접근 → 드래그 콩! 밀어내기 루프
2. 밀려난 요정 연출(비눗방울·엉덩방아) + "띠용~/통통!" 사운드 + 열려도 다시 숨기기
3. 요정 3종 선택 + 로비 카드 + 소프트 엔딩

**다음에 미룸 (≤3)**

1. 별사탕 스티커 도감(`localStorage` 재방문 훅)
2. 상자 꾸미기(스티커·색)
3. 장소 변주(거실/부엌/정원)
