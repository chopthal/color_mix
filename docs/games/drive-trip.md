# 게임 구상: 부릉부릉 드라이브 (drive-trip)

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

• 경로: `games/drive-trip/`
• 상태: **Done(2단계 본편)** — 사용자 최종 피드백 대기
• 갱신: 2026-11-28

---

## 1. 한 줄 놀이

운전석에 앉아 핸들을 돌리고 페달을 꾹 눌러 동네 길을 달린다. 빵빵 하면 느린 차가 비켜 주고, 빨간불엔 손을 떼서 멈춘다.

## 2. 감정 한 줄

"내가 진짜 운전했어!" — 어른 흉내의 뿌듯함 + 신호를 지켜 낸 자신감.

## 3. 코어 루프 (30초~1분 = 신호등 하나 구간)

1. 아이 입력: 오른쪽 **원페달**(누르면 감 / 떼면 스르르 멈춤) · 왼쪽 **핸들**(좌우 드래그) · 핸들 가운데 **빵빵**
2. 즉각 반응: 엔진음 피치·속도감(가로수 흐름) · 핸들 회전 · 경적음
3. 화면에 남는 변화: 느린 차가 깜빡이 켜고 갓길로 비켜 손 흔듦 / 신호등 앞 정지 → 동물 친구들이 횡단보도를 건넘
4. 다시 하고 싶게: 초록불 "출발!" → 다음 동네 풍경 → 도착지

화면 (2~4장):

1. 1인칭 운전석: 앞 유리 너머 3D 도로, 하단 좌 핸들 · 우 페달 · 조수석 친구
2. 앞에 느린 경운기 → 빵빵 → 갓길로 비켜 손 흔듦
3. 빨간불 → 정지선 반짝 → 멈춤 → 동물 건너기 → 초록불 출발
4. 도착 → "도착!" → 더 할래 / 쉬자

### 3-1. 조작 계약 (합의 2026-11-28)

- **원페달:** 누르고 있는 동안 가속(최고속 도달 ~3초), 떼면 ~2초에 걸쳐 부드럽게 정지. 별도 브레이크 없음.
- **핸들 = 차선 자석 보정:** 손을 놓아도 차가 길을 따라감. 핸들은 차선 변경·회피용. 도로 밖 이탈 불가. 핸들 그림을 정확히 잡지 않아도 화면 좌측 하단 영역 아무 데서나 좌우 드래그.
- **충돌 없음:** 앞차에 가까워지면 자동으로 속도를 맞춰 따라감(“쿵” 없음).
- **기기 우선순위:** 태블릿 가로 → 폰 가로. 세로도 깨지지 않게(조작은 하단 양 구석).

### 3-2. 신호등 유도 4단계 (No Penalty)

1. 멀리서 신호등이 크게 보이고, 빨간불이면 정지선이 반짝
2. 조수석 친구 말풍선 + 페달이 살짝 깜빡 (손 떼기 유도)
3. 계속 누르고 있어도 **정지선 앞에서 자동으로 부드럽게 멈춤**(매직 브레이크). 실패 연출 없음
4. 멈춘 동안 동물 친구들이 횡단보도를 건넘(보상) → 초록불 → 페달 반짝 "출발!"

- 스스로 손을 떼서 멈추면 별 반짝 + 칭찬, 매직 브레이크면 담백한 "같이 멈췄다" (차등 칭찬만, 벌점 없음)
- 빨간불 중 정지선 통과·건너는 동물과의 접촉은 **구조적으로 불가**(동물은 차가 정지선 앞 완전 정지 후에만 출발)

### 3-3. 클락션

- 앞 차선에 느린 차(경운기 등) 등장 → 빵빵 → 깜빡이 켜고 갓길로 비켜서 손 흔듦
- 앞에 아무것도 없을 때 빵빵: 길가 새가 날아오르는 등 작은 발견 리액션
- 경적은 "안녕~ 먼저 갈게" 인사 프레이밍(공격·화남 연출 금지)

## 4. 첫 90초

로비 진입 → 시동 버튼(큰 열쇠) 탭(오디오 제스처 해제 겸) → 페달이 반짝 + 손가락 힌트 → 누르면 출발.

• 막힐 수 있는 지점: 페달을 탭만 하고 뗌(조금 가다 멈춤) / 핸들을 모름
• 막힘 완화: 정지 상태 5초 → 페달 반짝 힌트 · 핸들은 몰라도 진행 가능(자석 보정) · 첫 신호등은 항상 빨간불(정지 학습 1회 보장)

## 5. 변주·질림 방지

• 변주 축 (2단계): **목적지(장소)** · **날씨/시간대**
• 발견 레이어: 빈 길 경적 리액션 · 대시보드 버튼(깜빡이·와이퍼·라이트·라디오) — 2단계
• 선택할 수 있는 것: 차선 · 목적지 카드(2단계) · 갈림길 방향(2단계)
• 목표 세션 길이: 3~5분(한 여행) · 출구: 도착 화면 "더 할래 / 쉬자"

**10회차 체크:** 목적지별 구간 조합(8~10종) × 날씨 × 이벤트 순서 랜덤 — 2단계에서 충족.

## 6. 소프트 엔딩

• 도착지에 서서히 정차 → "도착!" 연출 → 더 할래 / 쉬자 (평가·점수 없음)
• 도우미 멘트 방향: 다음에 또 / 쉬러 가자 (§6-1 과몰입 금지)

## 8-A. 2단계 본편 명세 (2026-11-28 확정 — 사용자 "알아서 끝까지 완성" 위임으로 오케스트레이터 결정)

### 흐름
도장 지도(시작 화면) → 목적지 카드 4장 중 선택 → 차고 앞 시동 → 여행(3~4분, 1,300~1,700m) → 도착 연출 → 도장 쾅 → 소프트 엔딩(더 할래 = 도장 지도로 / 쉬자 = 로비)

### 목적지 4곳 · 구간 테마 (구간 순서는 고정 틀 + 이벤트 배치 랜덤)

| 목적지 | 구간 흐름 | 도착지 연출 |
|------|------|------|
| 🏖️ 바닷가 | 동네 → 논밭 → 해안도로 | 모래사장·파도·갈매기·파라솔 |
| 🦒 동물원 | 동네 → 숲길 → 터널 → 숲길 | 동물원 정문 + 담 너머 기린 목 |
| 🏡 할머니 댁 | 동네 → 논밭(기차 건널목) → 다리 → 시골길 | 감나무 시골집 + 꼬리 흔드는 강아지 |
| 🎡 놀이공원 | 동네 → 시장 거리 → 세차장 → 다리 | 관람차·풍선 아치 |

- 구간 테마 7종: 동네 · 논밭 · 해안도로 · 숲길 · 시골길 · 시장 거리 · 다리(강·작은 배). 터널·세차장·기차 건널목은 구간 안 **이벤트 지형**.
- 이벤트 풀(여행당): 신호등 2~3(첫 신호 항상 빨강, 이후 빨강/초록 랜덤) · 느린 차 1~2(경운기 — 짐 종류 랜덤) · 목적지 고유 이벤트 1개(기차 건널목 / 터널 / 세차장 / 해안 전망) · 빈 길 발견(새·나비·물고기 점프 등 테마별).

### 새 이벤트 규칙 (모두 No Penalty, 매직 브레이크 보장)
- **기차 건널목:** 땡땡땡 경보음 + 차단기 내려옴 → 신호등과 같은 정지 4단계(스스로 정지 칭찬 / 매직 브레이크) → 귀여운 기차(4량) 통과 → 차단기 올라감 → 출발.
- **터널:** 진입 시 어두워짐(무섭지 않게 주황 조명등 줄) → 라이트 버튼 반짝 유도(안 켜도 진행) → 켜면 전조등 빛 · 경적은 메아리.
- **세차장:** 서행 자동(매직 리밋) → 회전 브러시·거품·물줄기가 앞 유리를 덮었다 걷힘 → 와이퍼 버튼 반짝(누르면 거품 쓱 닦임).
- **날씨/시간대 (여행마다 랜덤):** 맑음 50% · 노을 20% · 비 15% · 눈 15%. 비: 앞 유리 빗방울 + 와이퍼 유도 · 노을: 라이트 유도 · 눈: 눈송이·하얀 지붕.

### 대시보드 버튼 (발견 레이어, 하단 띠)
깜빡이(◀ ▶, 딸깍 소리 + 화살표 점멸, 핸들로 차선 바꾸면 자동 점등) · 와이퍼 · 라이트 · 라디오(오리지널 짧은 합성 멜로디 3곡 순환). 모두 선택 — 안 눌러도 진행.

### 조수석 친구 "토리" (새 캐릭터 · 확정 디자인)
아기 다람쥐. 도토리 모자, 빵빵한 볼, 크고 둥근 눈, 갈색 털 + 크림색 배. 스타일 A(두꺼운 외곽선 플랫) SVG. 표정 3종: 기본 · 신남(눈 웃음) · 말하기(입 뻐끔). 말할 때 통통 튐.

### 재방문 훅: 여행 도장 지도
- 시작 화면 = 일러스트 지도 위 목적지 4곳. 다녀온 곳엔 도장 + 방문 점(최대 5개). `KidsKit.store('drive-trip')` (`visits: {sea, zoo, grandma, park}`, `metTori: bool`).
- 첫 방문만 토리 인사, 이후엔 바로 "오늘은 어디 갈까?".
