# 게임 구상: 색깔 섞기

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

• 경로: `games/color-mix/`
• 상태: Done(이번 범위)
• 갱신: 2026-11-11

---

## 1. 한 줄 놀이

물감(과일·꽃·하늘 재료)을 톡톡 눌러 그릇에 넣고, 섞여 나온 새 색 이름을 구경해요.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **신기한 뿌듯** — "내가 만든 색이 도감에 남고, 다시 와도 반겨 준다."

## 3. 코어 루프 (30초~2분)

1. 아이 입력: 아래 팔레트에서 색(재료) 버튼을 톡.
2. 즉각 반응(시청각): 그릇에 점이 쌓이고 배경색이 섞이며, 짧은 톡 소리·햅틱. 색 이름 TTS(스피커 버튼).
3. 화면에 남는 변화: 섞인 색 이름·레시피 문구, "내가 만든 색" 도감에 새 버튼(비슷한 색은 중복 없이 펄스만).
4. 다시 하고 싶게 만드는 것: "다시!"로 그릇을 비우고 다른 조합·다른 테마 재료로 또 섞기.

화면으로 설명하면 (4장면):

1. 테마 칩(과일/꽃/하늘) + 빈 그릇 "색깔을 눌러 섞어 보세요!"
2. 색 톡 → 그릇이 물들고 재료 점·레시피 표시.
3. 새 색이면 도감에 팝 등장, 특별 조합이면 반짝 연출.
4. 몇 번 섞으면 "잘 섞었어" 소프트 엔딩(또 할래 / 쉬자).

## 4. 첫 90초

로비 → 진입 → 첫 색 버튼 탭까지 약 2~5초.

• 막힐 수 있는 지점: 테마·도감이 많아 보여 어디를 눌러야 할지 모름.
• 막힘 완화: 기본 테마가 바로 선택됨. 그릇 안내 문구가 첫 행동만 안내. 색 버튼 ≥70px. 정답 없음.

## 5. 변주·질림 방지

• 변주 축 (1~2개만): **재료 테마**(과일 / 꽃 / 하늘) — 같은 섞기 루프, 그릇·버튼 모양·배경 톤만 바뀜.
• 발견 레이어 (1회차에 숨길 것): 빨강+노랑+파랑 동시 섞기 → 무지개 반짝. 드문 이름(금색·민트 등) 첫 발견 시 반짝.
• 선택할 수 있는 것: 어떤 색을 몇 개 넣을지, 테마, 도감에서 만든 색 재사용.
• 목표 세션 길이: 3~5분 · 출구: 소프트 엔딩 "또 할래 / 쉬자" + 상시 "쉬자".

**10회차 체크:** 테마를 바꾸면 같은 색도 다른 모양으로 보이고, 아직 못 만든 조합·특별 연출이 남음. 도감이 쌓여 "내 색"이 늘어남.

## 6. 소프트 엔딩

질리거나 부모가 끊을 때:

• 끝나는 느낌(평가·실패 화면 없이): 이번 세션에서 그릇을 비운 섞기(재료 2개 이상)가 약 5회면 "잘 섞었어!" 카드. 점수·실패 없음.
• 선택: **또 할래**(세션 카운트 리셋, 계속 섞기) · **쉬자**(놀이터).
• 현실·휴식: 과몰입 유혹 멘트 없음. "쉬자"로 로비 복귀.

## 7. 재방문 훅 (1개만)

유형: 수집·도감

• 한 줄: "돌아왔을 때 지난번에 만든 색이 도감·환영 띠로 반겨 준다"
• 저장: `KidsKit.store('color-mix')` — 만든 색 목록·마지막 색·발견 특별·방문 수
• 금지: 완성 압박·남과 비교·랭킹

## 8. 이번 범위 Done

**반드시 넣음 (≤3)**

1. 재료 테마 3종(과일/꽃/하늘) + 동일 RYB 섞기 루프
2. 만든 색 도감 영속 저장 + 재방문 "지난번 만든 색" 반김
3. 소프트 엔딩·쉬자 + 무지개/특별색 발견 연출 + 이미지 슬롯 폴백

**다음에 미룸 (≤3)**

1. 실사·생성 이미지로 테마 그릇·재료 교체(매니페스트만 준비)
2. 부모용 "오늘 만든 색" 요약 카드
3. 더 많은 특별 조합·계절 테마

## 10. 합의 메모

• 핵심 기술: RYB 큐브 보간 + 흰/검 질량 → 최근접 한글 색 이름. 테마는 시각만 바꿈.
• 소프트 엔딩 트리거: 세션 내 `다시!`(재료 ≥2) 5회.
• 이미지: `assets/slots.json`의 `ready`에 이름을 넣은 뒤 `KidsKit.assets.preload`. webp 없으면 `ready: []` → CSS 도형 폴백.
