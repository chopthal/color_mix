# 게임 구상: 칙칙폭폭 호박 특장차와 사탕 미로 대모험

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

• 경로: `games/pumpkin-train/`  
• 상태: Done(이번 범위) — 2단계 고도화  
• 갱신: 2026-11-11  

---

## 1. 한 줄 놀이

호박 차에 달콤한 사탕 수레를 길게 달고 마법 포털을 넘어 파티장으로 출발하는 블록 코딩 미로 놀이!

## 2. 감정 한 줄

“내가 길을 뚫고 사탕 기차를 이만큼 길게 만들었어! 내 호박 차도 멋지게 꾸몄지!” (성취감과 소유감)

## 3. 코어 루프 (30초~2분)

1. **아이 입력**: 하단 팔레트에서 방향 블록([⬆️][⬇️][⬅️][➡️]) 및 [특수 액션] 탭 연결.
2. **즉각 반응(시청각)**: 블록 누를 때마다 바닥에 반투명 호박 발자국이 '퐁퐁' 미리 찍힘. [출발 ▶️] 터치 시 차가 "칙칙폭폭" 주행.
3. **화면에 남는 변화**:
   - 사탕 통과 시 차 뒤에 수레가 하나씩 연결되어 꼬리가 길어짐.
   - 호박 바위/솜사탕을 해결하고, 마녀 모자에 쏙 들어가 반대편으로 뿅! 순간이동.
4. **다시 하고 싶게 만드는 것**:
   - 파티장 도착 시 사탕 폭죽과 함께 '호박 왕관', '박쥐 날개' 등 새 파츠 획득!
   - 획득한 파츠로 차고에서 호박 차를 자유롭게 꾸며 다음 맵 주행.

화면으로 설명하면:

1. 블록을 콕 → 발자국 프리뷰
2. 출발 → 사탕·장애물·워프 통과
3. 파티장 도착 → 파츠 해금
4. (4단계 후) 차고 자랑 → 쉬자 소프트 엔딩

---

## 4. 첫 90초

로비 진입 → 첫 **의미 있는** 터치까지:

• **막힐 수 있는 지점**: 워프 터널 방향 헷갈림 / 틀린 특장차로 액션
• **막힘 완화**:
  - 발자국 프리뷰가 마녀 모자 입·출구까지 번호로 안내
  - 틀린 차 액션 시 “다른 차로 바꿔 볼까?” + 맞는 차 버튼 반짝 (실패 화면 없음)
  - 멈춘 자리에서 이어하기(No Reset)

---

## 5. 변주·질림 방지

• **변주 축 (2개)**:
  1. **맵 기믹**: 사탕길 → 바위 밀기 → 솜사탕 주스 → 마녀 모자 워프 (4스테이지)
  2. **시드 배치**: 같은 기믹·출발/골인 고정, 사탕·장애물·워프 칸만 `layoutSeed % 10`으로 재배치 (10회차 변주)
• **발견 레이어**:
  1. 마녀 모자 워프 마법 가루/발자국
  2. 재방문(2회+) 시 사탕 획득에 가끔 박쥐 반짝(`🦇✨`)
• **선택**: 불도저 ↔ 주스차, 파츠 탈부착
• **목표 세션 길이**: 3~5분 · 출구: KidsKit `restButton` + 4단계 후 소프트 엔딩

**10회차 체크:** 시드가 돌 때마다 사탕·바위/거미줄·워프 위치가 달라져 같은 루프에 작은 새로움이 남음.

## 6. 소프트 엔딩

• **끝나는 느낌**: 4스테이지 클리어 → 승리 모달 → **차고에서 차 자랑** → KidsKit softEnding  
  제목: “오늘 모험 대성공! 예쁜 호박 차와 사탕 친구들이 편안히 쉬러 가요”
• **현실·휴식 연결**: “또 할래” 시 힌트에 “손 씻고 맛있는 간식 먹으러 갈까?” 방향 / “쉬자”는 로비
