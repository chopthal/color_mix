# 게임 구상: 바닷속 까꿍 & 허그 놀이

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

• 경로: `games/ocean-peekaboo/`
• 상태: 구현 중 · 1차 Done 범위 반영
• 갱신: 2026-10-30

원 아이디어(아이): **상어 = 숨기, 고래 = 잡기**.  
재해석: 포식·포획을 제거하고 **잠꾸러기 상어와 까꿍**, **반가운 아기 고래와 하이파이브(안아주기)** 로 정서적으로 안전하게 바꾼다.  
발달 목표: 만 4세 **신호에 따른 행동 전환·충동 조절(Go/No-Go)**.

---

## 1. 한 줄 놀이

잠수부(나)가 바닷속에서, 졸린 상어가 오면 미역 뒤에 쏙 숨고, 아기 고래가 오면 터치로 꼭 안아 주는 까꿍·허그 놀이.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **포근함 + “내가 잘 숨고·잘 안아 줬다”는 뿌듯함** (공포·공격성 없음)

## 3. 코어 루프 (약 30초~1분 / 한 이벤트)

1. **아이 입력**
   - **숨기(No-Go):** 화면의 미역·산호·바위(은신처)를 **직접 터치** → 잠수부가 그 뒤로 쏙 숨음
   - **안아주기(Go):** 화면에 나타난 **아기 고래를 직접 터치** → 하이파이브·간지럼·하트 연출
2. **즉각 반응(시청각)**
   - 은신처 터치: 잠수부 쏙 들어가는 바운스 + “쏙!” 짧은 효과음
   - 고래 터치: 고래가 하트를 뿜으며 빙글 춤 + 간지럼 웃음 소리(또는 “잡았다!” 효과음)
3. **화면에 남는 변화**
   - 상단(또는 가장자리)에 **부드러운 진행 표시**: 고래 허그 횟수(목표 5), 상어 까꿍 성공 횟수(목표 3) — 숫자 강요 없이 하트·물방울 아이콘이 하나씩 채워짐
   - 성공/실패와 무관하게 바닷속 배경은 계속 잔잔히 흐름
4. **다시 하고 싶게 만드는 것**
   - 다음 예고 신호(물줄기 / 지느러미)가 곧 다시 나타남
   - 도우미(아기 거북이)의 짧은 칭찬·안심 멘트

화면으로 설명하면 (2~4장면):

1. 잔잔한 바닷속 · 잠수부(아이)와 아기 거북이 · 미역/산호 은신처가 큼직하게 보임
2. **예고(약 3초)** → 상어 또는 고래 등장
3. 은신처 터치로 숨기 / 고래 터치로 허그 → 따뜻한 리액션 (실패해도 패널티 없음)
4. 목표 충족 시 노을·보랏빛 바다 → 한 판 마무리

### 3-1. 핵심 로직 (코드 없이 재구현 가능 수준)

#### 캐릭터·역할

| 역할 | 정체 | 행동 요약 |
|------|------|-----------|
| 주인공 | 잠수부(아이) | 평소 헤엄·대기. 은신처 터치 시 숨음. 숨은 동안은 다른 은신처로만 이동 가능(선택 구현) |
| 신호 A (No-Go) | 잠꾸러기 상어 | 무섭지 않은 귀여운 친구. 낮잠 가며 지나감. “잡아먹음” 연출 금지 |
| 신호 B (Go) | 아기 고래 | 놀러 온 친구. 터치하면 허그/하이파이브. 작살·그물·포획 연출 금지 |
| 도우미 | 아기 거북이 | 상황별 짧은 대사(§3-3). 정답 강요·재촉 금지 |
| 은신처 | 미역·산호·바위 | 터치 영역 큼직(권장 64px↑). 여러 개 배치해 “고를 수 있음” |

#### 라운드·이벤트 상태 흐름

한 판 = 여러 **이벤트**의 연속. 이벤트 종류는 `shark` | `whale`.

1. **Idle(대기)**  
   - 짧은 쉬는 간격(예: 1.5~3초, 랜덤 가능) 후 다음 이벤트 종류를 고름.  
   - 같은 종류가 과도하게 연속되지 않게(예: 동일 종류 최대 2연타 후 강제 교차) 하면 Go/No-Go 전환 연습에 유리.
2. **Telegraph(예고, 약 3초)** — 갑자기 튀어나오지 않음  
   - **고래 예고:** “보글보글~ 푸우!” 물줄기 소리 + 화면 **아래**에서 무지개 물방울이 올라옴  
   - **상어 예고:** 느리고 코믹한 바순 톤(“두둥~ 쿨쿨~”) + 화면 **구석**에 작은 지느러미가 천천히 지나감  
   - 이 구간에서 도우미 멘트(§3-3) 가능. 입력은 받아도 됨(미리 숨어 두기 허용 — 충동 조절·예측 연습).
3. **Active(등장·반응 창)**  
   - 상어/고래가 화면에 들어와 일정 시간 머무르거나 가로질러 감(권장 체류 약 3~5초, 재촉 타이머 UI 없음).  
   - **상어 Active**  
     - 성공: 잠수부가 **은신 상태**이면 → 까꿍 성공 카운트 +1, 상어는 모르고 지나감, 성공 연출·멘트  
     - 실패: 은신 아님(상어와 “마주침”) → 카운트 증가 없음, **하트 감소·게임오버·잡아먹힘 없음**. 상어가 “어라? 들켰네! 까꿍~” 하며 웃고 지나감 + 안심 멘트  
   - **고래 Active**  
     - 성공: 고래 **본체(큼직한 터치 영역)** 터치 → 허그 카운트 +1, 하트·춤 연출·멘트  
     - 실패(미터치로 고래가 화면 밖으로): 카운트 증가 없음, 고래가 손 흔들며 “다음에 또 놀자!” 헤엄쳐 감. 패널티 없음  
   - Active 중 잘못된 행동(예: 상어일 때 빈 바다만 연타)은 무시하거나 아주 약한 시각 힌트만. 혼내기 없음.
4. **Resolve(짧은 여운)** → Idle로 복귀  
5. **Session Soft End**  
   - 조건(둘 다 충족): **고래 허그 ≥ 5** AND **상어 까꿍 성공 ≥ 3**  
   - 바닷속에 노을이 지고 보랏빛으로 변함 → 도우미가 현실·휴식 연결 멘트 → 로비/부모 이야기 유도  
   - 한 판 목표 호흡 **3~5분**. 목표 전에 부모가 나가도 실패 화면 없음.

#### 은신 상태 규칙

- 은신처 터치 → `hidden = true`, 잠수부 스프라이트가 해당 은신처 뒤로 이동·일부 가려짐  
- 은신 해제: (1) 상어 이벤트가 끝난 뒤 자동으로 다시 나오기(까꿍!), 또는 (2) 바다 빈 곳 터치로 나오기 — 1차는 **이벤트 Resolve 후 자동 나오기**를 권장(조작 단순)  
- 상어 Active 시작 시점에 `hidden == true`이면 성공으로 판정(미리 숨어 두기 OK)

#### 금지 연출 (제품 가드레일)

- 상어가 쫓아오거나, 잠수부를 삼키거나, 빨강 경고·하트 깎기  
- 고래를 작살·그물·케이지로 “포획”  
- 점수 경쟁·랭킹·제한 시간 프로그레스 바(초 세기 UI)  
- 어둠·괴물화·피·비명

### 3-2. 예고·등장 시청각 힌트 (요약)

| 이벤트 | 예고(약 3초) | 등장 톤 |
|--------|--------------|---------|
| 고래 | 보글보글 물줄기 + 무지개 물방울↑ | 밝고 반가운 등장 |
| 상어 | “두둥~ 쿨쿨~” + 구석 지느러미 | 느리고 코믹·졸린 등장 |

### 3-3. 도우미(아기 거북이) 상황별 대사 규칙

원칙: 한 번에 **2~3문장 이하**, 긍정·청유, 평가·재촉 금지 (`docs/PROJECT.md` §6-1).

| 상황 | 대사 방향 (확정 원고 후보) |
|------|---------------------------|
| 상어 예고 | “쉿! 꾸벅꾸벅 졸린 상어가 지나가네. 우리 미역 이불 속으로 쏙 숨어볼까?” |
| 숨기 성공 | “와, 진짜 감쪽같이 숨었다! 상어가 모르고 지나갔어. 까꿍!” |
| 숨기 실패(마주침) | “앗, 상어랑 눈이 마주쳤네! 상어가 ‘안녕?’ 하고 인사하고 간다.” |
| 고래 예고 | (짧고 밝게) 물방울을 가리키며 고래가 온다는 기대감 — 확정 시 한 줄 추가 |
| 고래 허그 성공 | “고래를 꼭 잡았네! 고래가 간지러워서 까르르 웃나 봐!” |
| 고래 미터치 | “고래가 손 흔들며 가네. 다음에 또 안아 주자!” |
| 세션 종료(노을) | “와, 이제 고래랑 상어도 코 자러 갈 시간이래. 우리도 물 밖으로 나가서 엄마(아빠)랑 이야기 나누자!” |

담당 소유: 위 후보는 합의 원고로 반영. 구현 시 문구를 추측으로 늘리지 않는다.

## 4. 첫 90초

로비 진입 → 첫 **의미 있는** 터치까지:

• 막힐 수 있는 지점: “무엇을 눌러야 하는지” 불명, 상어 예고를 공포로 오해  
• 막힘 완화:
  - 시작 직 거북이가 미역을 한 번 콕 가리키며 “여기는 숨는 곳” 힌트(동의 후·짧게)
  - 은신처·고래 터치 영역 매우 큼직
  - 첫 이벤트는 **고래(Go)** 로 시작해 성공 경험을 먼저(선택 권장) → 이후 상어 섞기
  - 상어는 이빨·혈안 연출 없이 눈 비비는 졸린 표정

## 5. 변주·질림 방지

• **변주 축 (1~2개만)**  
  1. **신호 종류 교차** (상어 까꿍 ↔ 고래 허그) — 핵심 Go/No-Go  
  2. **은신처·배경 소품** (미역/산호/바위 위치·색, 작은 물고기 지나감)  
• **발견 레이어 (1회차에 숨길 것):** 허그 연속 성공 시 고래가 가끔 특별한 하트 색·짧은 춤 변주  
• **선택할 수 있는 것:** 여러 은신처 중 어디에 숨을지  
• **목표 세션 길이:** 3~5분 · 출구: 노을 soft ending 또는 언제든 로비로(실패 없음)

**10회차 체크:** 같은 루프 10번에도 남는 작은 새로움 — 예고 연출·은신처 위치·고래 춤/하트 변주·상어가 지나가는 방향

## 6. 소프트 엔딩

질리거나 목표가 찼을 때:

• **끝나는 느낌:** 노을·보랏빛 바다, 친구들이 코 자러 감. 평가·별점·실패 화면 없음  
• **도우미 멘트:** §3-3 세션 종료 문구 — 과몰입(“나만의 친구/가지 마”) 금지, **부모·현실**로 연결

## 7. 재방문 훅 (1개만)

유형: **돌봄·관계** (가볍게) + 장면에 남는 온기

• 한 줄: “돌아왔을 때 **아기 거북이가 잠수부를 반갑게 맞이**하고, 지난번에 안아 준 고래가 멀리서 한 번 손을 흔든다”  
• 저장 필요 여부: 1차는 **없어도 됨**(매회 새 판). 재방문 연출만 고정 연출로 가능. 허그/까꿍 누적 도감은 2차  
• 금지: 경쟁·랭킹·완성 압박·과몰입 유혹

## 8. 이번 범위 Done

**반드시 넣음 (≤3)**

1. **Go/No-Go 코어:** 예고 3초 → 상어 까꿍(은신처 직접 터치)·고래 허그(고래 직접 터치) · 실패 시 따뜻한 미스 연출만 · 게임오버·하트 깎기 없음  
2. **한 판 목표·소프트 엔딩:** 고래 허그 5 + 상어 까꿍 성공 3 달성 시 노을·보랏빛 + 거북이 현실 복귀 멘트  
3. **고정 캐릭터 비주얼 + 기본 효과음**(물방울·쿨쿨·쏙·하트) 및 합의 대사 텍스트(화면/말풍선). TTS는 브라우저 가능 범위에서만 보조

**다음에 미룸 (≤3)**

1. 아이가 그린 상어·고래 스캔 캐릭터 교체  
2. 아이 목소리 “까꿍!” / “잡았다!” 녹음 효과음  
3. 누적 도감·localStorage 재방문 심화, 은신처 스킨 해금
