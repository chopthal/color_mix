# 게임 구상: 바닷속 까꿍 & 허그 놀이

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

• 경로: `games/ocean-peekaboo/`
• 상태: 2단계 고도화 반영 · 플레이 가능
• 갱신: 2026-11-11

원 아이디어(아이): **상어 = 숨기, 고래 = 잡기**.  
재해석: 포식·포획을 제거하고 **잠꾸러기 상어와 까꿍**, **반가운 아기 고래와 하이파이브(안아주기)** 로 정서적으로 안전하게 바꾼다.  
발달 목표: 만 4세 **신호에 따른 행동 전환·충동 조절(Go/No-Go)**.

---

## 1. 한 줄 놀이

잠수부(나)가 바닷속에서, 졸린 상어가 오면 미역 뒤에 쏙 숨고, 아기 고래가 오면 터치로 꼭 안아 주는 까꿍·허그 놀이.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **포근함 + “내가 잘 숨고·잘 안아 줬다”는 뿌듯함** (공포·공격성 없음)

## 3. 코어 루프 (약 30초~1분 / 한 이벤트)

1. **아이 입력**
   - **숨기(No-Go):** 화면의 미역·산호·바위(은신처)를 **직접 터치** → 잠수부가 그 뒤로 쏙 숨음
   - **안아주기(Go):** 화면에 나타난 **아기 고래를 직접 터치** → 하이파이브·간지럼·하트 연출
2. **즉각 반응(시청각)**
   - 은신처 터치: 잠수부 쏙 들어가는 바운스 + “쏙!” 짧은 효과음
   - 고래 터치: 고래가 하트를 뿜으며 빙글 춤 + 간지럼 웃음 소리(또는 “잡았다!” 효과음)
3. **화면에 남는 변화**
   - 상단 진행 표시: 고래 허그(목표 7), 상어 까꿍 성공(목표 5) — 하트·물방울 아이콘이 하나씩 채워짐
   - 성공/실패와 무관하게 바닷속 배경은 계속 잔잔히 흐름
4. **다시 하고 싶게 만드는 것**
   - 다음 예고 신호(물줄기 / 지느러미)가 곧 다시 나타남
   - 도우미(아기 거북이)의 짧은 칭찬·안심 멘트
   - 매 판 은신처·물고기 배치/색 셔플, 허그 연속 시 숨은 춤·하트 색

화면으로 설명하면 (2~4장면):

1. 잔잔한 바닷속 · 잠수부(아이)와 아기 거북이 · 미역/산호 은신처가 큼직하게 보임
2. **예고(약 3초)** → 상어 또는 고래 등장
3. 은신처 터치로 숨기 / 고래 터치로 허그 → 따뜻한 리액션 (실패해도 패널티 없음)
4. 목표 충족 시 노을·보랏빛 바다 → 한 판 마무리

### 3-1. 핵심 로직 (코드 없이 재구현 가능 수준)

#### 캐릭터·역할

| 역할 | 정체 | 행동 요약 |
|------|------|-----------|
| 주인공 | 잠수부(아이) | 평소 헤엄·대기. 은신처 터치 시 숨음 |
| 신호 A (No-Go) | 잠꾸러기 상어 | 무섭지 않은 귀여운 친구. 낮잠 가며 지나감. “잡아먹음” 연출 금지 |
| 신호 B (Go) | 아기 고래 | 놀러 온 친구. 터치하면 허그/하이파이브. 작살·그물·포획 연출 금지 |
| 도우미 | 아기 거북이 | 상황별 짧은 대사. 재방문 시 반김 인사 |
| 은신처 | 미역·산호·바위 | 터치 영역 큼직. 매 판 위치·색 셔플 |

#### 라운드·이벤트 상태 흐름

한 판 = 여러 **이벤트**의 연속. 이벤트 종류는 `shark` | `whale`.

1. **Idle(대기)** — 약 2.8~4.5초 후 다음 이벤트
2. **Telegraph(예고, 약 3초)** — 고래: 물방울↑ / 상어: 구석 지느러미
3. **Active(등장·반응 창, 약 5초)**
   - 상어: 은신이면 까꿍 성공, 아니면 따뜻한 미스(“안녕?”)만. 하트 깎기·게임오버 없음
   - 고래: 본체 터치 시 허그 성공. 미터치면 손 흔들며 퇴장
4. **Resolve** → Idle
5. **Session Soft End** — 고래 허그 ≥ 7 AND 상어 까꿍 ≥ 5 → 노을 + 휴식 멘트. 중간 출구: `KidsKit.restButton`(쉬자)

#### 변주·발견 (2단계)

- **변주 축:** (1) 은신처 위치·색 셔플 (2) 떠다니는 물고기 이모지·위치·색 셔플 — 난이도 상승 없음
- **발견 레이어:** 허그 **연속 2회**부터 무지개 하트 + 스핀 춤, **3회**부터 황금·반짝 하트. 1회차 첫 허그는 기본 연출만
- **재방문 훅:** `KidsKit.store('ocean-peekaboo')`에 `visits`·`lastHugs` 저장. 재진입 시 타이틀 스킵 → 거북이 손흔들 인사 + (지난 허그>0이면) 멀리 고래 손흔들

#### 타이틀·첫 터치

- 첫 방문: 타이틀 오버레이 **어디든 탭**(로비 링크 제외)으로 시작 — 버튼만 찾아야 하는 탭 낭비 완화
- 재방문: 타이틀 없이 바로 인사 연출 후 플레이

#### 이미지 슬롯

`games/ocean-peekaboo/assets/<이름>.webp`가 있으면 표시, 없거나 로드 실패 시 기존 SVG 코드 드로잉 폴백.  
슬롯: `diver`, `turtle`, `whale`, `shark`, `kelp`, `coral`, `rock`, `sea-bg`.  
매니페스트: `tools/imagegen/manifests/ocean-peekaboo.json`.

#### 금지 연출

- 상어가 쫓아오거나 삼키거나 하트 깎기
- 고래 포획·그물
- 점수 경쟁·초치기 UI·공포 연출

## 5. 변주·질림 방지

• **변주 축:** 은신처·물고기 위치/색 · 신호 교차(상어↔고래)  
• **발견 레이어:** 허그 연속 시 특별 하트·춤  
• **목표 세션 길이:** 3~5분 (허그 7 + 까꿍 5, Idle 2.8~4.5초) · 출구: 노을 soft ending + 쉬자 버튼

## 6. 소프트 엔딩

노을·보랏빛 바다 + 커스텀 종료 패널(“코 잘 시간이야”) + 한 번 더 / 놀이터로. 중간에는 `KidsKit.restButton`.
