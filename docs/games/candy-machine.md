# 게임 구상: 달콤 사탕 자판기와 치카치카 (candy-machine)

## 1. 한 줄 놀이

동전 짤랑 넣고 음료수 자판기처럼 사탕을 퐁! 뽑아 껍질을 까고, 쪽쪽 녹여 먹으며 치카치카 칫솔질로 충치균을 말끔히 씻어내는 생활습관 놀이.

## 2. 감정 한 줄

내가 원하는 사탕을 직접 뽑는 **설렘과 재미** + 사탕은 쪽쪽 녹여 먹어야 안전하다는 **깨달음** + 치카치카로 이를 반짝반짝 닦아내는 **개운함과 뿌듯함** + 먹어 본 사탕이 **치아 스티커**로 남는 **수집 기쁨**.

## 3. 코어 루프 (30초~2분)

1. **동전 넣고 자판기 뽑기:** 동전 투입 → 12종 버튼 점등 → 낙하 → 배출구 문 **톡! 슬라이드 오픈** → 사탕 꺼내기
2. **사탕 까기:** 포장지 탭 3회로 알맹이 등장
3. **먹기:** 쪽쪽(종류별 맛·표정 변주) vs 아작(아야·반창고)
4. **선택:** 또 먹기 / 치카치카 → 양치(드래그 또는 입 톡톡) 완료 시 반짝 소프트 엔딩
5. **세션:** 여러 사탕 → 양치 → 엔딩으로 **3~5분** 호흡 (플레이 중 `쉬자` 상시). 가로 모드도 자판기·동전이 화면 안에 맞춤.

화면으로 설명하면:

1. 자판기 + 동전 + (재방문 시) 치아 스티커 줄·반김 카드
2. 문 열림 → 포장 까기 → 맛 리액션
3. 또 먹기 루프 / 치카치카 → 반짝 엔딩

## 4. 첫 90초

- 진입 시 동전이 통통 튐(손가락 가이드).
- 재방문·스티커 있으면 상단 반김 카드(“OO 사탕 기억해!”) 3~4초.
- 막힘 완화: 동전 → 버튼 → 문 톡 → 꺼내기 순 힌트 문구.

## 5. 변주·질림 방지

• **변주 축 (2개):**  
  1) **사탕 종류별 맛 리액션** — 쪽쪽 멘트·표정(happy/sour/sparkle)·파티클(heart/sparkle/bubble)  
  2) **치아 스티커 도감** — 먹어 본 id만 상단 스티커로 쌓임  
• **발견 레이어:** 레몬·소다 등 새콤/톡톡 표정은 해당 사탕을 골라야 보임. 스티커는 먹은 뒤에만 생김.  
• **선택:** 12종 사탕, 쪽쪽/아작, 또 먹기/양치  
• **목표 세션:** 3~5분 · 출구: 플레이 중 `쉬자`(KidsKit.restButton) + 엔딩 “또 먹기 / 쉬자”

**10회차 체크:** 아직 안 먹은 사탕의 맛·표정·스티커가 남고, 문 열림 반짝도 매번 기분 좋음.

## 6. 소프트 엔딩

• 양치 완료: “치카치카 대성공!” / 스티커 있으면 개수 반영  
• 플레이 중 언제든 `쉬자` → 로비 (실패·점수 없음)  
• 과몰입·재촉 문구 없음 (§6-1)

## 7. 재방문 훅 (1개)

유형: **수집·도감** (+ 가벼운 반김)

• 한 줄: “돌아왔을 때 먹어 본 사탕 **치아 스티커**와 ‘OO 사탕 기억해!’ 카드가 반겨 준다”  
• 저장: `KidsKit.store('candy-machine')` — `eaten`(id 배열), `brushWins`, `visits`  
• 금지: 완성 압박·경쟁·결핍 문구 없음
