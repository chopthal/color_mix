# 게임 구상: 신나는 마법 한글 쓰기 (hangul)

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

• 경로: `games/hangul/`
• 상태: Done(이번 범위)
• 갱신: 2026-11-11

---

## 1. 한 줄 놀이

꼬마 자동차로 자음 도로를 따라가며 기역~히읗을 그리고, 단어 친구(가위·나비…)를 완성하는 획 놀이.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **“내가 글자 도로를 다 그렸어!”라는 뿌듯함** + 도장 친구가 늘어나는 **설렘**

## 3. 코어 루프 (약 30초~2분 / 한 단어 단계)

1. 아이 입력: 자동차 핸들을 잡아 현재 획의 점선 도로를 따라 끝까지 드래그
2. 즉각 반응(시청각): 웨이포인트마다 짧은 종소리·별 파티클·햅틱. 획 끝에서 다음 시작점으로 Hop
3. 화면에 남는 변화: 주황 도로가 채워짐 → 단어/자음 완성 축하 레이어 → 탭에 ⭐·도장
4. 다시 하고 싶게 만드는 것: 같은 자음의 다음 단어 단계(기본→단어1→단어2→받침/3단계), 또는 다른 자음 탭

화면으로 설명하면 (2~4장면):

1. 장소 테마(교실/놀이터/바다) 칠판·무대 + 상단 자음 탭
2. 도로 슬롯에 자동차·끝점 펄스 링 → 드래그로 칠하기
3. 완성! 이모지·짧은 칭찬 → 다음 단어 / 다음 글자
4. (선택) 몇 글자 후 소프트 엔딩 · 도장 도감

### 3-1. 핵심 로직 (코드 없이 재구현 가능)

#### 자음·코스

- 자음 14개: `ㄱㄴㄷㄹㅁㅂㅅㅇㅈㅊㅋㅌㅍㅎ`
- 자음마다 **4단계 코스** (`HANGUL_COURSES`): 단독 자음 → 세로모음 단어 → 가로모음 단어 → 받침(또는 ㅎ은 하늘처럼 초성 단어)
- 획 좌표는 `CHAR_STROKES` (정통 획순). `ㅇ`/`ㅎ` 동그라미는 12시에서 반시계 원 점열

#### 드래그·스냅

1. 손가락은 자유, 자동차 위치만 **현재 획 폴리라인의 최근접점**으로 스냅
2. 다음 웨이포인트 반경(약 42 SVG 단위) 안에 들어오면 웨이포인트 진행 + 도로 `path` 갱신
3. 획의 마지막 점 도달 → 남은 획이 있으면 Hop(시작점 이동), 없으면 단계 완료

#### 진행 영속 (`KidsKit.store('hangul')`)

| 키 | 의미 |
|----|------|
| `stars` | 자음별 완료 단계 수 0~4 (⭐ 영속) |
| `clearedChars` | 4단계 모두 끝낸 자음 배열(도장) |
| `themeId` | 현재/마지막 장소 테마 id |
| `todayFriend` | `{ date, char }` — 그날의 글자 친구 |
| `visitCount` | 방문 횟수 |

세션 중 `sessionClears`(이번 방문에서 4단계 완료한 글자 수)는 메모리만. **2글자** 완료 시 소프트 엔딩.

#### 장소 테마 (변주 축)

같은 획 놀이, 장소만 바꿈. 테마 id: `classroom` | `playground` | `ocean`.

- 진입·「또 할래」·글자 탭 전환 시 **순환 또는 저장값 복원**
- 무대 배경색·테두리·장식 이모지·자동차 이모지 폴백만 바뀜 (획 데이터 불변)

#### 재방문

1. `clearedChars`가 있으면 짧은 반김 배너: “오늘 이 글자 친구는 ○야!”
2. `todayFriend.char`는 당일 고정. 없으면 클리어 목록에서 고르거나 다음 미클리어 자음
3. 탭에 저장된 ⭐/`cleared` 도장 복원

#### 소프트 엔딩·출구

- `KidsKit.restButton` 상시(로비)
- 세션에서 자음 **2개** 풀클리어 후 `KidsKit.softEnding` (“잘했어!” / 또 할래 / 쉬자)
- 또 할래 → 세션 카운터 리셋, 테마 한 칸 순환, 이어서 놀이

## 4. 첫 90초

로비 진입 → 첫 **의미 있는** 터치까지:

• 막힐 수 있는 지점: 자동차를 어디로 끌지 모름
• 막힘 완화: 끝점 펄스 링 + 가이드 문구 TTS + 도로 점선이 이미 보임. 첫 드래그만 하면 종소리로 성공감

## 5. 변주·질림 방지

• 변주 축 (1~2개만): **장소 테마**(교실 칠판 / 놀이터 / 바다) · **자음·단어 선택**(14탭)
• 발견 레이어 (1회차에 숨길 것): 도장 도감 채움 · 재방문 “오늘 글자 친구”
• 선택할 수 있는 것: 자음 탭, 테마는 세션 흐름으로 순환(강제 난이도↑ 없음)
• 목표 세션 길이: **3~5분** · 출구(“또 할래 / 쉬자”)

**10회차 체크:** 같은 루프 10번 때 아직 남는 작은 새로움: 다른 자음·다른 장소 테마·도장 한 칸 더

## 6. 소프트 엔딩

질리거나 부모가 끊을 때:

• 끝나는 느낌(평가·실패 화면 없이): “글자 친구랑 잘 놀았어!” + 또/쉬자
• 현실·휴식 연결: 쉬자 → 놀이터 홈. 과몰입(“가지 마”) 멘트 없음

## 7. 재방문 훅 (1개만)

유형: 수집·도감 + 돌봄 반김

• 한 줄: “돌아왔을 때 **오늘 이 글자 친구**가 반겨 주고, 예전에 찍은 **도장**이 그대로 있다”
• 저장: `KidsKit.store('hangul')` localStorage
• 금지: 경쟁·랭킹·완성 압박·과몰입 유혹
