# 게임 구상: 포근포근 밤밤 (Cozy Night)

`docs/PROJECT.md` §8 체크리스트의 게임별 작성본.

• 경로: `games/cozy-night/`
• 상태: Done (2단계 고도화)
• 갱신: 2026-11-11

---

## 1. 한 줄 놀이

동물 친구에게 이불을 덮어주고 토닥토닥 재우며 맑은 오르골 자장가를 들어요.

## 2. 감정 한 줄

끝나고 아이가 느꼈으면 하는 것: **포근함 + 안심 + 나른한 졸림** — "동물 친구도 잘 자네, 나도 이제 포근하게 코 자야지."

## 3. 코어 루프 (한 친구당 ~1분, 세션 3~5분)

1. 아이 입력: **토닥** → **이불 덮기** → **별 켜기 또는 오르골** (수면 의식 3단).
2. 즉각 반응(시청각):
   - 토닥: 오르골 퐁·하트/별 파티클, 눈이 스르륵 감김 (별 게이지 5칸)
   - 이불: 사르륵 소리 + 동물×이불 무늬 **조합 반김** (예: 꿀잠 이불, 꽃밭 이불)
   - 별/오르골: 밤 큐 완료 → 새근새근 정착(~4초) 후 친구 잠듦
3. 화면에 남는 변화: 의식 도트(🫶🛌✨) 채워짐, 잠든 친구 뱃지 💤, Zzz 파티클.
4. 다시 하고 싶게: 다른 동물 친구도 같은 의식으로 재우기 → 2명 재우면 세션 소프트 엔딩.

화면으로 설명하면 (4장면):

1. 아늑한 밤방: 침대에 동물 친구가 눈을 말똥말똥 뜨고 있음.
2. 토닥·이불·별/오르골 의식: 힌트 문구가 다음 단계를 부드럽게 안내.
3. 친구 잠듦 토스트: "○○가 새근새근… 다른 친구도 재워줄까?"
4. 취침 엔딩: 오르골·꿈나라·놀이터/쉬자 출구.

## 4. 첫 90초

로비 진입 → 침대 위 동물 친구와 별이 반짝임 → 첫 **의미 있는** 터치(별 또는 동물 토닥이기)까지 3초 이내.

• 막힐 수 있는 지점: 무엇을 먼저 눌러야 할지 모름 / 토닥만 하고 엔딩이 안 남.
• 막힘 완화: 게이지 힌트가 다음 단계(이불→별/오르골)를 안내. 손가락 힌트 1회. 순서 강요 없이 어디서든 즉시 반응.

## 5. 변주·질림 방지

• 변주 축 (1~2개): **동물 친구 3종** × **이불 무늬 3종**(노랑·핑크·파랑) 조합 반김.
• 발견 레이어: (1) 달님 톡 → 윙크 😉 (2) 귀 쪽 터치 → 귀 쫑긋 후 다시 포근.
• 선택할 수 있는 것: 동물, 이불 색, 별/오르골, 불 끄기.
• 목표 세션 길이: **3~5분** · 출구: 취침 엔딩 / KidsKit **쉬자** / 놀이터 🏠.

**10회차 체크:** 9가지 동물×이불 조합 문구·파티클 + 달 윙크·귀 쫑긋이 남음.

## 6. 소프트 엔딩

• 끝나는 느낌: 친구 2명을 재우면(또는 "코 잘 시간이야") 취침 오버레이. 중도 **쉬자**는 KidsKit softEnding.
• 현실·휴식 연결: "친구들이 새근새근 잠들었어요. 우리 친구도 좋은 꿈 꿔요. 쉿, 내일 또 만나요!" (재촉·과몰입 유혹 없음).

## 7. 재방문 훅 (1개만)

유형: 루틴 / 돌봄·관계

• 한 줄: "돌아왔을 때 어젯밤 재워준 친구가 기분 좋게 기지개를 켜며 반겨 준다"
• 저장: `KidsKit.store('cozy-night')` — `lastFriend`, `lastBlanket`, `lastVisitAt`, `putToSleepCount`.
• 금지: 연속 출석 압박, 놓치면 사라지는 보상, 과몰입 멘트 없음.

## 8. 이번 범위 Done (2단계)

**반드시 넣음 (≤3)**

1. 수면 의식 호흡(토닥→이불→별/오르골) + 친구당 ~1분·다수 친구로 세션 3~5분.
2. 동물×이불 조합 반김 + 달 윙크·귀 쫑긋 발견 레이어.
3. 재방문 기지개 반김 + KidsKit 쉬자/에셋 슬롯/매니페스트.

**다음에 미룸 (≤3)**

1. 백색소음(빗소리, 파도소리) 선택 믹서.
2. 부모 설정 타이머(지정 분 후 디스플레이 슬립 가이드).
3. 추가 동물 친구(아기 양, 부엉이).
