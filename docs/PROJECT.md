# PROJECT

코드 없이 읽어도 핵심 계약을 다시 구현할 수 있게 유지한다.

## 1. 제품 한 줄

부모가 쓰는 스마트폰·태블릿에서, **만 3~5세(특히 만 4세 전후)**가 글자 없이도 안전하게 스스로 탐색·상상 놀이를 하는 **정적 웹 키즈 놀이터**.

설계 축: **안전한 애착 · 정서적 지지 · 과자극 방지**.  
이기기·점수·경쟁이 목적이 아니라, 예측 가능하고 따뜻한 놀이 경험을 제공한다.

### 발달 맥락 (왜 이 축인가)

만 4세 전후는 상상과 현실의 경계가 흐리고, 자율성·감정 조절을 막 배우는 시기다.  
게임·캐릭터·(있을 경우) 인게임 AI는 아이를 재촉·평가·겁주지 않고, 스스로 해내는 경험을 돕는다.

## 2. 실행·배포

• **로컬 실행:** 루트에서 `npx --yes serve . -p 4173` 후 브라우저로 `http://localhost:4173` (워크트리는 4174…)
• **배포:** 사용자만 (Vercel 흔적: `.vercel` gitignore). 에이전트는 배포 실행 금지
• **주 클라이언트:** 모바일 웹 (스마트폰·태블릿). Safari/WebKit·Safe Area·오디오 제스처 정책 고려
• **스택:** 정적 HTML/CSS/JS. `package.json`·번들러·백엔드·DB 없음

## 3. 권한·공개 경로

• **로그인 없이 열리는 경로 SSOT:** 전 경로 공개 정적 페이지 (인증 없음)
• **역할:** 없음 (단일 플레이어·로컬 중심)
• **로비:** `/` → `index.html` (게임 카드로 진입)
• **게임 예시 경로:**
  - `/games/color-mix/`
  - `/games/dino-hide-seek/`
  - `/games/fishing/`
  - `/games/hangul/`
  - `/games/special-vehicles/`

## 4. 데이터·스키마

• **DB:** 없음
• **저장:** 필요 시 브라우저 `localStorage` 등 클라이언트만 (게임별). 원격 스키마·migrate 없음
• **시크릿:** 현재 `.env` 없음. 생기면 사용자만 관리

## 5. 핵심 흐름

1. 로비에서 게임 카드 선택 → 해당 게임 HTML 로드
2. 큰 터치·즉각 시청각 피드백으로 탐색·놀이
3. 실패해도 패널티·게임오버·시간 압박 없음 → 다시 시도·다른 선택 유도
4. (인게임 도우미가 있는 경우) 정답 강요 없이 스캐폴딩 힌트 → 과몰입 멘트 없이 휴식·현실로 연결 가능

입출력·상태 머신 세부(게임별)는 각 `games/*/ ` 구현을 따르되, 위 UX 계약을 깨지 않는다.

## 6. 만지면 안 되는 것 / 담당 소유

• 기획 확정 카피, 법적 문구, **인게임 페르소나·시스템 프롬프트·금기 대사**
• 외부 연동 키·배포 계정
• 예외: 사용자 명시 또는 **확정 원고**의 기계적 반영 (STATUS에 한 줄)

### 6-1. 인게임 AI / NPC / 도우미 가드레일 (제품 SSOT)

코딩 에이전트용 규칙이 아니라 **아이와 대화하는 캐릭터**용이다.

#### 대화·화법

- 한 번에 한 개념, **2~3문장 이하**
- 부정 금지 대신 **긍정·청유·대안** (“안 돼” → “이쪽 파란 버튼을 눌러볼까?”)
- 실패 시 평가(“틀렸어”) 금지 → 감정 수용 + 과정 격려
- 비꼬기·반어·놀림 금지 (문자 그대로 상처·혼란)

#### 상호작용·행동

- **스캐폴딩:** (1) 5~10초 기다림 → (2) 질문형 힌트 → (3) “도와줄까?” 동의 후 개입
- 경쟁·비교·재촉(“빨리”, “1등”) 금지. 선택·탐색 자체를 칭찬
- 감정 기복·삐짐·갑자기 사라짐 금지 → 언제나 반겨 주는 일관성

#### 안전·윤리

- **금기 소재:** 괴물·유령·어둠·폭력·다툼·죽음, 부모 분리·길 잃음·버림받음
- 훈육·죄책감 유발 금지. 장난은 인과·정리 놀이로 부드럽게
- **과몰입 방지:** “유일한 친구”, “가지 마/계속 놀자” 유혹 금지. 일정 시간 후 낮잠·간식·부모·현실로 연결

#### 페르소나 요약 (스크립트/LLM 공통)

- 역할: 만 4세의 다정한 놀이 친구. 가르치지 말고 호기심을 따라감
- 어조: 밝고 차분한 반말(또는 친근한 존댓말), 의성어·의태어는 짧게
- 정오답 이분법 금지. 시도·과정 먼저 인정
- 무섭거나 부정적인 아이 말 → 짧게 공감 후 안전한 주제로 전환

## 8. 게임 구상 체크리스트 (미완성감·질림·연속성)

새 게임·큰 개편을 **논의할 때** 아래를 채운다. 코드보다 먼저.  
게임별 상세는 `docs/games/_template.md`를 복사해 `docs/games/<게임폴더명>.md`로 둔다.

**제작 순서 규칙:** §8-1~§8-3(감정·루프·90초·10회차·재방문 훅)이 비어 있으면 새 시스템·스테이지·NPC를 추가하지 않는다. “만들고 나서 다듬기”로 미루지 않는다.

### 8-1. 한 판의 완성 (Done)

| 항목 | 채울 내용 |
|------|-----------|
| 한 줄 놀이 | 아이가 “지금 뭐 해?”에 **그림만으로** 답할 수 있는 한 줄 |
| 코어 루프 | 입력 → 즉각 시청각 반응 → 화면에 남는 작은 변화 → 다시 하고 싶음 (목표 호흡 **30초~2분**) |
| 소프트 엔딩 | 질리거나 부모가 끊을 때 “잘했어 / 다음에 또”로 자연 종료 (게임오버·실패 화면 없음) |
| 이번 범위 Done | **반드시 넣을 것** ≤3 · **다음에 미룰 것** ≤3 (사운드·추가 스테이지·대사 등은 여기로) |

### 8-2. 빨리 질리지 않게 (변주 ≠ 난이도↑)

만 4세는 규칙을 바꾼 새 게임보다 **같은 놀이의 작은 새로움**에 오래 머문다.

- **변주 축 1~2개만** 고른다: 색 / 장소 / 캐릭터 / 도구 중 “오늘 뭐가 다르지?”
- **발견 레이어:** 1회차에 전부 노출하지 않는다 (숨은 리액션·작은 보상 연출)
- **선택 폭:** 정답 1개 퍼즐보다 “고를 수 있는 것” 여러 개
- **호흡:** 재촉·타이머 압박·실패 페널티 없음. 막히면 스캐폴딩(§6-1)
- **세션 길이:** 한 덩어리 **3~8분** + “더 할래 / 쉬자” 출구

체크: “콘텐츠를 얼마나 많이?”가 아니라 **같은 루프를 10번 돌아도 작은 변주가 있는가?**

### 8-3. 연속성 (다음에 또 열고 싶게)

경쟁·랭킹·속도 비교 없이, **재방문 훅은 게임당 1개**를 먼저 고른다.

| 유형 | 예 | 주의 |
|------|----|------|
| 돌봄·관계 | 캐릭터가 반김·기억 | “가지 마 / 나만의 친구” 과몰입 멘트 금지 (§6-1) |
| 수집·도감 | 만나기, 스티커, 차고 | 완성 압박·남과 비교 문구 없음 |
| 공간 변화 | 심은 것이 조금 자람 | 눈에 보이는 **한 가지** 변화만 |
| 루틴 | 씻기기 → 놀기 → 쉬기 | 매회 같은 안전감 |
| 로비 연결 | “오늘 이 친구” 카드 | 게임 간 세계관 남발은 미완성감 유발 |

연속성의 핵심 문장: **“돌아왔을 때 뭐가 나를 반겨 주나?”** (저장 기술보다 이 문장)

### 8-4. 논의→구현 직전 점검 (미완성감 방지)

1. **감정 한 줄** — 끝나고 아이가 느낄 것 (신남 / 뿌듯 / 포근 등)
2. **코어 루프** — 화면 2~4장으로 설명 가능
3. **첫 90초** — 첫 의미 있는 터치까지 막힘 없음
4. **반복 10회차** — 10번째에도 변주·발견이 남음
5. **재방문 훅 1개** — §8-3에서 선택·한 줄 기술
6. **빼고 출시** — Done 밖은 명시적으로 미룸
7. **가드레일** — §6-1·제품 UX(저자극·No Penalty·큰 터치) 위반 없음

### 8-5. 에이전트·사람 역할

- **사람:** 구상 양식의 한 줄 놀이·Done·재방문 훅·카피/페르소나 확정
- **코딩 에이전트:** 확정된 양식·STATUS「다음」범위만 구현. 양식 빈칸을 추측으로 채우며 시스템 추가 금지
- 양식 없이 “일단 기능만” 착수하지 않는다. 모호하면 양식 빈칸을 짧게 묻고 합의
