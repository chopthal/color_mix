# 아트 스타일 가이드 (초안 — 사람 확정 필요)

대상: 만 3~5세(특히 만 4세 전후). 과자극·무서움·날카로움 금지.  
이 문서는 **초안**이다. 스타일 후보 중 하나를 사람이 고른 뒤 `tools/imagegen/style-prefix.txt`에 반영한다.

## 1. 스타일 방향 후보

### A. 두꺼운 외곽선 플랫 (Bold Outline Flat)

- **느낌:** 또렷한 실루엣, 큰 색면, 만화 스티커
- **장점:** 작은 화면·한손 터치에서도 형태 인식이 빠름. 상태 변주(톡/활짝) 구분이 쉬움. 용량·리사이즈에 강함
- **단점:** 너무 단순하면 “장난감 앱” 느낌으로 질릴 수 있음. 선 두께·팔레트가 흔들리면 세계관이 깨짐

### B. 부드러운 파스텔 그림책 (Soft Pastel Picture-book)

- **느낌:** 연한 그라데이션·보송한 가장자리, 동화책 삽화
- **장점:** 정서적 안전감·따뜻함과 제품 축(안전한 애착)에 잘 맞음. 휴식·돌봄 테마와 궁합
- **단점:** 대비가 약하면 야외·밝은 OLED에서 읽힘 저하. 배경 제거·키잉이 상대적으로 까다로움

### C. 클레이/소프트 스컬피 (Clay / Soft Sculpt)

- **느낌:** 둥근 점토 덩어리, 살짝 입체감, 손맛
- **장점:** “만질 수 있을 것 같은” 촉감 연상 → 터치 놀이와 잘 맞음. 캐릭터 애착에 유리
- **단점:** 생성 모델이 그림자·하이라이트를 과하게 넣기 쉬움(통일 규칙 필수). 용량이 커질 수 있음

**권장(초안):** 1차 파일럿은 **A 또는 B** 중 하나. C는 앵커 이미지로 톤을 강하게 고정할 수 있을 때.

## 2. 공통 규칙 (스타일 확정 후에도 유지)

1. **시점:** 정면 또는 **3/4 정면**. 극단적 아래/위 앵글·일그러진 원근 금지
2. **비례:** 큰 머리, 짧은 팔다리, **둥근 형태**. 공룡 뿔·가시·이빨 등은 있어도 되지만 끝을 둥글게 단순화(리얼한 날카로움 금지)
3. **표정:** 기본은 온화·호기심. 대결 게임의 귀여운 '으쌰' 표정·삐짐·승리 환호는 허용. 리얼한 공포·위협 표정 금지 (`docs/PROJECT.md` §6-1)
4. **팔레트:** 게임당 **5~8색**으로 제한. 네온·고채도 깜빡임 조합 금지
5. **배경:** **완전 투명** 산출물. 생성 단계에서는 키잉용 **단색 크로마**(기본 `#00FF00`) 평평한 배경으로 찍은 뒤 파이프라인이 제거
6. **그림자:** 없애거나, 확정 시 **아주 옅은 접촉 그림자 1종**만 전 에셋 통일. 임의 드롭섀도 혼용 금지
7. **텍스트:** 이미지 안에 글자·숫자·로고 넣지 않음 (글자 없는 UX)
8. **한 에셋 한 주제:** 프레임에 소품을 잔뜩 넣지 않음. 실루엣이 한눈에 읽혀야 함

## 3. 해상도·포맷·용량

| 규칙 | 내용 |
|------|------|
| 생성 크기 | **표시 CSS 픽셀의 2배** (예: 화면에 96px → 192×192 생성) |
| 포맷 | **WebP** (알파 유지) |
| 품질 | sharp WebP quality 약 80을 기본으로 시작, 디테일 깨지면만 올림 |
| 용량 가이드 | 캐릭터/소품 **≤ 80KB**, 큰 배경/배경 판 **≤ 200KB**을 목표(가이드, 절대 한도 아님) |
| 정사각 기본 | 캐릭터·아이템은 정사각 캔버스 우선. 필요 시 매니페스트 `width`/`height`로 명시 |

## 4. 경로·명명 규칙

```text
games/<게임폴더>/assets/<이름>[-<상태>].webp
games/_shared/assets/<이름>[-<상태>].webp   # 공용 캐릭터·공통 UI 조각
```

- `<이름>`: 소문자 케밥 (`raindrop`, `cloud`, `flower-red`)
- `<상태>`: 선택 (`idle`, `tap`, `bloom`, `seed`, `sprout` …)
- 예: `games/music-garden/assets/cloud-tap.webp`
- 예: `games/_shared/assets/buddy-wave.webp`

원본·임시 PNG는 레포에 커밋하지 않는다. 생성 스크립트 임시물은 `tools/imagegen/.gitignore` 대상.

## 5. 프롬프트에 넣을 고정 제약 (요약)

스타일 문장(후보 A/B/C) + 공통 규칙 +  
`flat solid chroma key background #00FF00, no drop shadow, no text, kid-safe, soft shapes`.

상세 실행 흐름은 [`image-pipeline.md`](./image-pipeline.md).
