# 키즈 놀이터

만 3~5세용 정적 웹 미니게임 모음. 로비(`index.html`)에서 각 게임으로 진입한다.

로컬 미리보기: `npx --yes serve . -p 4173`

**에이전트(코딩)는 `AGENTS.md`부터 읽고, `STATUS.md`「다음 할 일」만 진행한다.**  
제품 계약·인게임 가드레일: `docs/PROJECT.md`

## 오프라인(기내) 사용법

이 놀이터는 PWA라서 Wi-Fi에 한 번 접속해 두면 비행기 모드에서도 로비와 17개 게임 전부를 쓸 수 있다.

1. **출발 전 Wi-Fi 상태에서** 브라우저로 접속 → 서비스 워커가 전체 에셋(글꼴·이미지·게임)을 미리 받는다(최초 1회, 약 7MB).
2. **홈 화면에 추가** (iOS Safari: 공유 → “홈 화면에 추가” / Android Chrome: 메뉴 → “앱 설치”).
3. **비행기 모드로 바꾼 뒤** 홈 화면 아이콘으로 열어 로비와 게임이 정상 동작하는지 확인.

- 안드로이드에서 음성(읽어주기)은 기기 내장 TTS를 쓰므로, **Google TTS 한국어 오프라인 음성 데이터를 미리 내려받아** 둔다.
- 파일(HTML·JS·CSS·이미지·글꼴·json 등, 코드 포함)을 추가/변경하면 **`node tools/pwa/build-precache.mjs`를 다시 실행**해 `sw-precache.js`를 갱신해야 한다.
